## จุดที่ตัวอย่างนี้สาธิต

| เทคนิค | จุดที่อยู่ในร่าง |
|---|---|
| ใช้เลขไทยทั้งฉบับ (ที่อยู่ เบอร์โทร วันที่ จำนวนสิ่งที่ส่งมาด้วย) | ทุกตัวเลขในเนื้อหา ยกเว้น placeholder `[เลขที่ ........./..........]` |
| คำขึ้นต้น "เรียน" + คำลงท้าย "ขอแสดงความนับถือ" สำหรับอธิบดี (บุคคลทั่วไป ตามภาคผนวก ๒) | บรรทัด "เรียน อธิบดีกรม ข." และ "ขอแสดงความนับถือ" |
| ย่อหน้าที่ ๑ ขึ้นต้นด้วย "ตามที่..." (ใช้เมื่อตอบหนังสือฉบับก่อน) | "ตามที่กรม ข. ได้มีหนังสือ..." |
| ย่อหน้าสุดท้ายขึ้นต้น "จึงเรียนมาเพื่อโปรดพิจารณา..." | บรรทัดสุดท้ายของเนื้อหา |
| placeholder เลขที่หนังสือและวันที่ — เว้นว่างให้สารบรรณกลาง (ข้อ ๔๓) | `[เลขที่ ........./..........]` และ `[วัน เดือน ปี พ.ศ. ๒๕๖๙]` |
| อ้างถึง — ระบุที่และวันที่ของหนังสือฉบับก่อน | บรรทัด "อ้างถึง" |
| สิ่งที่ส่งมาด้วย — ระบุชื่อและจำนวน (ใช้ "ฉบับ" / "ชุด") | บรรทัด "สิ่งที่ส่งมาด้วย" |
| ส่วนราชการเจ้าของเรื่อง + โทรศัพท์/โทรสาร/อีเมล อยู่ท้ายหน้า | บล็อกล่างสุด |
| เว้น ๔ บรรทัดสำหรับลายมือชื่อ | ระหว่าง "ขอแสดงความนับถือ" กับ "(นาย ก.)" |

## checklist ปิดท้ายร่าง

```
สิ่งที่ผู้ใช้ต้องดำเนินการก่อนเสนอลงนาม
- [ ] ส่งให้งานสารบรรณกลางออกเลขที่หนังสือและลงวันที่
- [ ] ตรวจชื่อ-นามสกุลและตำแหน่งของผู้ลงนาม
- [ ] ตรวจที่อยู่ผู้รับให้ถูกต้อง (ถ้าส่งทางไปรษณีย์)
- [ ] เตรียมเอกสารแนบตามที่ระบุใน "สิ่งที่ส่งมาด้วย"
- [ ] เสนอผู้บังคับบัญชาตามลำดับชั้น
```

## หมายเหตุ

- หากผู้รับเป็น **นายกรัฐมนตรี / ประธานสภา / ประธานศาลสูงสุด / ประธานองคมนตรี / รัฐบุรุษ** ให้เปลี่ยน "เรียน" → "**กราบเรียน**" และ "ขอแสดงความนับถือ" → "**ขอแสดงความนับถืออย่างยิ่ง**" (ภาคผนวก ๒ แถว ๑๓ ตำแหน่งสูง)
- ตัวอย่างนี้ไม่มีข้อมูลส่วนบุคคลของประชาชน จึงไม่ต้องผ่าน Preflight A — หากเรื่องที่หารือพาดพิงถึงข้อมูลผู้ป่วย/คดี/เลขประจำตัวประชาชน ต้องหยุดและส่งต่อ DPO ก่อน (`references/06-data-safety.md`)
