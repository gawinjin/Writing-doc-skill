# ตัวอย่างหนังสือภายใน (บันทึกข้อความ) — เสนอขออนุมัติ

**สถานการณ์สมมุติ:** หัวหน้ากลุ่มงานพัฒนาบุคลากรเสนอผู้อำนวยการกองอนุมัติจัดอบรมภายใน

**Template ที่อ้างอิง:** `templates/02-internal.md`

เรียน  ผู้อำนวยการกองการเจ้าหน้าที่


        ตามแผนพัฒนาบุคลากรประจำปีงบประมาณ พ.ศ. ๒๕๖๙ กลุ่มงานพัฒนาบุคลากร
ได้กำหนดให้มีการจัดโครงการอบรมเชิงปฏิบัติการเพื่อยกระดับทักษะการเขียนหนังสือราชการ
ของข้าราชการและพนักงานราชการในสังกัด นั้น


        กลุ่มงานพัฒนาบุคลากรพิจารณาแล้วเห็นว่า ในไตรมาสที่ ๓ มีข้าราชการบรรจุใหม่

ผลผลิตที่ ๑ กิจกรรมพัฒนาบุคลากร จำนวน ๔๕,๐๐๐ บาท (สี่หมื่นห้าพันบาทถ้วน)

## จุดที่ตัวอย่างนี้สาธิต

| เทคนิค | จุดที่อยู่ในร่าง |
|---|---|
| ไม่มีครุฑ — ใช้แค่หัว "บันทึกข้อความ" | บรรทัดบนสุด |
| ใช้เลขไทยในเนื้อหา **ยกเว้นจำนวนเงินในตาราง/เนื้อหาการเงิน** ใช้เลขอารบิก ตามข้อยกเว้นมติ ครม. ๒ พ.ค. ๒๕๔๓ | "๔๕,๐๐๐ บาท" — ยังคงเป็นเลขอารบิกเพราะเป็นจำนวนเงิน; วันที่และจำนวนคน "๑๕ ราย" "๒๐ ราย" ยังเป็นเลขไทย |
| คำขึ้นต้น "เรียน" + ไม่มีคำลงท้าย ("ขอแสดงความนับถือ") | บรรทัด "เรียน ผู้อำนวยการ..." — และไม่มี "ขอแสดงความนับถือ" |
| ย่อหน้าสุดท้าย "จึงเรียนมาเพื่อโปรดพิจารณาอนุมัติ" | ต่างจากหนังสือภายนอกที่ใช้ "เพื่อโปรดทราบ/พิจารณา" |
| ส่วนราชการเจ้าของเรื่องอยู่บนสุด มี โทรศัพท์ภายใน | "ส่วนราชการ กลุ่มงานพัฒนาบุคลากร..." |
| placeholder เลขที่และวันที่ — เว้นว่าง | `[เลขที่ กก ๐๐๐๐.๒/........]` และ `[วัน เดือน ปี พ.ศ. ๒๕๖๙]` |
| ลำดับ ๓ ย่อหน้า: ที่มา → ข้อเท็จจริง+ความเห็น → คำขอ | ๓ บล็อกในเนื้อหา |

## ข้อแตกต่างหลักจากหนังสือภายนอก

| หนังสือภายนอก | บันทึกข้อความ (ภายใน) |
|---|---|
| มีครุฑ | ไม่มีครุฑ |
| มี "เรียน" + "ขอแสดงความนับถือ" | มี "เรียน" — **ไม่มี** คำลงท้าย |
| ที่อยู่หน่วยงานอยู่มุมบนขวา | "ส่วนราชการ" อยู่บล็อกบนสุด |
| มี "อ้างถึง" / "สิ่งที่ส่งมาด้วย" เป็นรายการ | มีได้แต่ไม่บังคับ ส่วนใหญ่เขียนรวมในเนื้อหา |
| ลงท้ายด้วย ส่วนราชการเจ้าของเรื่อง + โทรศัพท์ | ไม่ต้องเขียนซ้ำท้ายหน้า (อยู่บนสุดแล้ว) |

## checklist ปิดท้ายร่าง

```
สิ่งที่ผู้ใช้ต้องดำเนินการก่อนเสนอลงนาม
- [ ] ส่งให้งานสารบรรณกลางออกเลขที่และลงวันที่
- [ ] ตรวจชื่อ-นามสกุลและตำแหน่งของผู้ลงนาม
- [ ] เตรียมเอกสารโครงการ/งบประมาณตามที่อ้างถึงในเนื้อหา
- [ ] เสนอผู้บังคับบัญชาตามลำดับชั้น (หัวหน้ากลุ่ม → ผอ.กอง → ผบ.ตามอำนาจอนุมัติ)
```
