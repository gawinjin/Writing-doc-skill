## จุดที่ตัวอย่างนี้สาธิต

| เทคนิค | จุดที่อยู่ในร่าง |
|---|---|
| หัว "ประกาศ[หน่วยงาน]" — กึ่งกลาง | "ประกาศกรม ก." |
| **ไม่มี "ที่"** เหมือนคำสั่งหรือหนังสือภายนอก — ประกาศไม่ออกเลขที่ทะเบียนหนังสือออก | สังเกตว่าไม่มี "ที่ X/พ.ศ." |
| เรื่อง — กึ่งกลาง ๒-๓ บรรทัด ตามด้วยขีดยาว | "เรื่อง รับสมัครบุคคล..." + "-----" |
| เนื้อหาขึ้นต้นด้วย "ด้วย..." (ใช้เมื่อแจ้งเรื่องใหม่) | "ด้วยกรม ก. ประสงค์จะรับสมัคร..." |
| โครงสร้างเป็นข้อ ๑, ๒, ๓ — ใช้เลขไทย | ๕ ข้อหลัก |
| ข้อย่อย ๒.๑, ๒.๒ — ใช้เลขไทยและจุด | "๒.๑ คุณสมบัติทั่วไป..." |
| จำนวนเงิน ใช้เลขอารบิก ตามข้อยกเว้นมติ ครม. ๒ พ.ค. ๒๕๔๓ | "๒๑,๐๐๐ บาท" / "๒๐๐ บาท" — ยังเป็นเลขอารบิก |
| **ตัวเลขจำนวนคน วัน เดือน พ.ศ. — ใช้เลขไทย** | "๒ อัตรา" / "๑๕ กรกฎาคม ๒๕๖๙" |
| ปิดท้ายด้วย "ประกาศ ณ วันที่..." (ไม่ใช่ "สั่ง ณ วันที่...") | บรรทัดก่อนลายมือชื่อ |
| ลายมือชื่อ + ชื่อ + ตำแหน่ง — ผู้มีอำนาจประกาศ | บล็อกท้าย |

## ข้อแตกต่าง ประกาศ vs แถลงการณ์ vs ข่าว

| ประเภท | ใช้เมื่อ | ตัวอย่าง |
|---|---|---|
| **ประกาศ** | แจ้งให้สาธารณะหรือผู้เกี่ยวข้องทราบสิ่งที่ส่วนราชการมีคำสั่ง/มติ/หลักเกณฑ์ | รับสมัคร ผลคัดเลือก ประกวดราคา หลักเกณฑ์ใหม่ |
| **แถลงการณ์** | ชี้แจงเหตุการณ์/ข้อเท็จจริง/ท่าทีของส่วนราชการต่อเรื่องที่สาธารณะให้ความสนใจ | กรณีเหตุการณ์ฉุกเฉิน คำชี้แจงข้อกล่าวหา |
| **ข่าว** | เผยแพร่ข้อมูลข่าวสารที่ส่วนราชการต้องการให้สาธารณะทราบ | ข่าวกิจกรรม ข่าวความสำเร็จ |

ทุกประเภทใช้รูปแบบเดียวกัน (ครุฑ + หัว + เรื่อง + เนื้อหา + วันที่ + ลายมือชื่อ) ต่างเพียง**คำหัว** ("ประกาศ" / "แถลงการณ์" / "ข่าว") และ**ระดับการเปิดเผย**

## คำที่ใช้ในประกาศ — สำนวนมาตรฐาน

| สำนวน | ใช้เมื่อ |
|---|---|
| "ด้วย ..." | เปิดประกาศแจ้งเรื่องใหม่ |
| "ตามที่ ... นั้น" | เกริ่นเรื่องที่มีหนังสือก่อน |
| "อาศัยอำนาจตามความใน ... จึงประกาศ ..." | กรณีต้องระบุฐานอำนาจ |
| "ประกาศ ณ วันที่ ..." | บรรทัดก่อนลายมือชื่อ — เลขอารบิก/ไทยตามมาตรฐานหน่วยงาน (default ไทย) |

## checklist ปิดท้ายร่าง

```
สิ่งที่ผู้ใช้ต้องดำเนินการก่อนเผยแพร่
- [ ] ตรวจรายละเอียดวันรับสมัคร / ระยะเวลา / อัตราเงินเดือน ให้ตรงกับ TOR/แผนสรรหา
- [ ] ตรวจคุณสมบัติเฉพาะให้ตรงกับมาตรฐานกำหนดตำแหน่ง (ก.พ.)
- [ ] ส่งร่างให้นิติกรหน่วยงานตรวจก่อนเผยแพร่
- [ ] ส่งให้งานสารบรรณกลางลงวันที่
- [ ] เผยแพร่ทางเว็บไซต์ของหน่วยงานและ job.ocsc.go.th (ถ้าเป็นพนักงานราชการ)
- [ ] เก็บสำเนาเข้าทะเบียนประกาศของหน่วยงาน
```
