# Examples — ตัวอย่างหนังสือราชการครบฉบับ

โฟลเดอร์นี้คือ **ตัวอย่างที่กรอกเสร็จแล้ว** ของหนังสือราชการแต่ละชนิด แตกต่างจาก `templates/` ที่เป็นโครง — ตัวอย่างเหล่านี้คือเอกสารสมมุติแต่ครบถ้วน เพื่อให้ Claude ใช้เป็น reference เมื่อร่างเอกสารชนิดเดียวกัน และเพื่อให้ผู้ใช้เห็นว่าหน้าตาของเอกสารที่ถูกต้องเป็นอย่างไร

ตัวอย่างทั้งหมดสร้างจาก verified specs ใน `references/` พร้อมอ้างอิง URL ของคู่มือ/ประกาศจริงจาก .go.th เพื่อให้ผู้ใช้ตรวจรูปแบบเปรียบเทียบ

## วิธีใช้ใน Skill

เมื่อผู้ใช้ขอร่างเอกสารชนิดใด หลังจากโหลด template ที่ตรงตาม `Loading map` ใน `SKILL.md` แล้ว ให้ Claude **อ่านตัวอย่างที่ตรงกับชนิดนั้นในโฟลเดอร์นี้ด้วย** เพื่อ:

1. **เห็นรูปแบบที่กรอกเสร็จแล้ว** — รวมทั้งระยะการขึ้นบรรทัดใหม่ เว้นบรรทัด ตำแหน่งของแต่ละบล็อก
2. **เลือกสำนวนมาตรฐาน** ที่เหมาะกับเรื่อง — ตารางสำนวนในแต่ละไฟล์ระบุไว้ว่าจะใช้ "ตามที่..." vs "ด้วย..." vs "อาศัยอำนาจตาม..." เมื่อใด
3. **ตรวจการใช้เลขไทย vs อารบิก** — ตัวอย่างชี้ทุกจุดที่ต้องสลับ (จำนวนเงิน → อารบิก, อื่น ๆ → ไทย)
4. **จำตำแหน่ง placeholder** — ทุกตัวอย่างเว้น `[เลขที่ ........./..........]` และ `[วัน เดือน ปี พ.ศ.]` ในตำแหน่งเดียวกันเสมอ

## ขอบเขตของตัวอย่าง

- ทุกตัวอย่างใช้ชื่อ ตำแหน่ง หน่วยงาน เป็นข้อมูลสมมุติ (กรม ก., นาย ก. กตัญญู, ฯลฯ) — ไม่ใช่ข้อมูลของบุคคล/หน่วยงานจริง
- ทุกตัวอย่างใช้รูปแบบที่ตรงตามระเบียบสารบรรณ พ.ศ. ๒๕๒๖ + ฉบับแก้ไขถึงฉบับที่ ๔ พ.ศ. ๒๕๖๔ และมติ ครม. ๒ พ.ค. ๒๕๔๓ (เลขไทย)
- ทุกตัวอย่างมี Source URL ของคู่มือ/ประกาศจริงจาก .go.th ให้ผู้ใช้กดเข้าไปตรวจรูปแบบเปรียบเทียบกับเอกสารจริงได้
- ตัวอย่างไม่ครอบคลุม: หนังสือถึงพระบรมวงศานุวงศ์ (ราชาศัพท์เฉพาะ), หนังสือต่างประเทศ (รูปแบบสากล), หนังสือลับ/ลับมาก/ลับที่สุด — สำหรับกรณีพิเศษเหล่านี้ ผู้ใช้ต้องตรวจ ภาคผนวก ๒ + ระเบียบความลับ พ.ศ. ๒๕๔๔ เพิ่มเติม

## ห้ามใช้ตัวอย่างเหล่านี้เป็น

- เอกสารจริงที่ส่งออกจากหน่วยงาน (ทุกฉบับต้องผ่านการตรวจของนิติกร/หัวหน้างาน + ลงนามโดยผู้มีอำนาจ + ออกเลขโดยสารบรรณกลาง)
- หลักฐานทางกฎหมายอ้างอิง (ตัวอย่างไม่ใช่เอกสารราชการจริง — อ้างอิงต้องไปที่ `references/07-regulation-index.md`)
