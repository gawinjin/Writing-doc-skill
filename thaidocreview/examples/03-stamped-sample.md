# ตัวอย่างหนังสือประทับตรา — แจ้งกำหนดวันรับเอกสาร

**สถานการณ์สมมุติ:** สำนักงานจังหวัดแจ้งกำหนดวันรับเอกสารโครงการให้องค์กรปกครองส่วนท้องถิ่นในจังหวัด

**Template ที่อ้างอิง:** `templates/03-stamped.md`
**ข้อสังเกต:** หนังสือประทับตราใช้ในกรณีที่ระเบียบสารบรรณข้อ ๑๕ กำหนด เช่น การตอบรับ การแจ้งผล การเตือน การส่งสิ่งของ ไม่ใช้ลายมือชื่อหัวหน้าส่วนราชการ แต่ใช้**ตราประทับ**ของส่วนราชการแทน

## จุดที่ตัวอย่างนี้สาธิต

| เทคนิค | จุดที่อยู่ในร่าง |
|---|---|
| ใช้คำว่า **"ถึง"** แทน "เรียน" — เป็นเครื่องหมายของหนังสือประทับตรา | บรรทัด "ถึง นายกองค์การบริหาร..." |
| ไม่มีคำลงท้าย ("ขอแสดงความนับถือ") และ**ไม่มีลายมือชื่อ** | ท้ายเนื้อหา |
| แทนที่ลายมือชื่อด้วย **ชื่อส่วนราชการเจ้าของหนังสือ + ตราประทับ + วันที่** | บล็อกท้ายเนื้อหา "สำนักงานจังหวัด ค. / [ตราประทับ] / [วันที่]" |
| ครุฑเล็กกว่าหนังสือภายนอก (๑.๕ ซม. แทน ๓ ซม.) | บนสุด |
| ที่หนังสือมี "ว" (เวียน) เพราะส่งหลายหน่วยรับ | `[เลขที่ มท ๐๐๐๐.๓/ว.........]` |
| ใช้เลขไทยทั้งฉบับ | ทุกตัวเลข |
| เนื้อหากระชับ ๒ ย่อหน้า: ที่มา + การแจ้ง | สั้นกว่าหนังสือภายนอก |

## ใช้หนังสือประทับตราเมื่อใด (ข้อ ๑๕ ของระเบียบสารบรรณ)

หนังสือประทับตราใช้ได้ใน ๖ กรณีดังนี้:

1. การส่งสิ่งของ เอกสาร หรือบรรณสาร
2. การตอบรับทราบที่ไม่เกี่ยวกับราชการสำคัญ
3. การแจ้งผลงานที่ได้ดำเนินการไปแล้วให้ส่วนราชการที่เกี่ยวข้องทราบ
4. การเตือนเรื่องที่ค้าง
5. เรื่องซึ่งหัวหน้าส่วนราชการระดับกรมขึ้นไปเห็นสมควรว่าไม่ใช่เรื่องสำคัญและให้ใช้หนังสือประทับตราได้
6. การแจ้งให้ทราบเป็นการทั่วไป (เช่น แจ้งกำหนดวัน หรือแนวปฏิบัติ)

ห้ามใช้สำหรับ: เรื่องสำคัญ, เรื่องเสนอนโยบาย, เรื่องตอบกลับการสอบสวน, เรื่องที่ต้องการลายมือชื่อรับผิดชอบของหัวหน้าส่วนราชการโดยตรง

## ข้อแตกต่างหลักจากหนังสือภายนอก

| หนังสือภายนอก | หนังสือประทับตรา |
|---|---|
| "เรียน [ตำแหน่ง]" | **"ถึง [ตำแหน่ง]"** |
| "ขอแสดงความนับถือ" | ไม่มีคำลงท้าย |
| ลายมือชื่อ + ชื่อ-ตำแหน่ง | **ตราประทับ** + ชื่อส่วนราชการ + วันที่ |
| ครุฑ ๓ ซม. | ครุฑ ๑.๕ ซม. |
| ใช้กับเรื่องสำคัญทั่วไป | ใช้เฉพาะ ๖ กรณีตามข้อ ๑๕ |

## checklist ปิดท้ายร่าง

```
สิ่งที่ผู้ใช้ต้องดำเนินการก่อนใช้
- [ ] ตรวจว่าเรื่องนี้เข้าข่าย ๖ กรณีของข้อ ๑๕ จริง — ถ้าไม่เข้าข่าย เปลี่ยนเป็นหนังสือภายนอกพร้อมลายมือชื่อ
- [ ] ส่งให้งานสารบรรณกลางออกเลขที่หนังสือและลงวันที่
- [ ] ส่งให้งานสารบรรณประทับตราของส่วนราชการ
- [ ] ระบุรายชื่อหน่วยรับให้ชัดเจน (เนื่องจากเป็นหนังสือเวียน "ว")
```

## หมายเหตุ

- หนังสือประทับตรา**ห้าม**ใช้กับเรื่องที่มีข้อมูลส่วนบุคคลของประชาชน — กรณีนั้นต้องใช้หนังสือภายนอกพร้อมลายมือชื่อหัวหน้าส่วนราชการ และต้องผ่าน Preflight A (`references/06-data-safety.md`) ก่อน
