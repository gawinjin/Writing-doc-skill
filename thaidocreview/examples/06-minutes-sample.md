## จุดที่ตัวอย่างนี้สาธิต

| เทคนิค | จุดที่อยู่ในร่าง |
|---|---|
| หัว ๔-๖ บรรทัดกึ่งกลางหน้า: ชื่อรายงาน + คณะ + ครั้งที่ + วัน + สถานที่ | บล็อกบนสุด |
| ๓ บล็อกผู้เข้าประชุม: ผู้มาประชุม / ผู้ไม่มาประชุม / ผู้เข้าร่วมประชุม | บล็อกที่ ๑-๓ |
| ระบุเหตุที่ไม่มาประชุม (เช่น "ติดราชการ") ใส่ในวงเล็บหลังหัวบล็อก | "ผู้ไม่มาประชุม (เนื่องจากติดราชการ)" |
| "เริ่มประชุมเวลา [เวลา] น." — บรรทัดเดี่ยว | บรรทัดก่อนวาระที่ ๑ |
| ระเบียบวาระมาตรฐาน ๕ วาระ (อาจมี ๖ ถ้ามีเรื่องที่ค้างจากครั้งที่แล้วแยกออก) | วาระ ๑-๕ |
| แต่ละวาระมีรูปแบบ: รายงาน/อภิปราย → "มติที่ประชุม [...]" | บล็อกของแต่ละวาระ |
| มติที่ประชุมเขียนกระชับ ตอบว่า "รับทราบ" / "เห็นชอบ" / "อนุมัติ" / "ให้ปรับปรุงและนำเสนอใหม่" | สังเกตทุกวาระมี "มติที่ประชุม" |
| "ปิดประชุมเวลา [เวลา] น." — บรรทัดเดี่ยว | ก่อนลายมือชื่อ |
| ๒ ลายมือชื่อท้ายรายงาน: ผู้จดรายงาน + ผู้ตรวจรายงาน | บล็อกท้าย |
| ใช้เลขไทยทุกตัว ยกเว้นจำนวนเงิน | "๕๐๐,๐๐๐ บาท" — เลขอารบิก; "๓ รุ่น" / "๖๕ คน" — เลขไทย |

## ระเบียบวาระมาตรฐาน

| วาระที่ | หัวข้อ | คำอธิบาย |
|---|---|---|
| ๑ | เรื่องที่ประธานแจ้งให้ที่ประชุมทราบ | เรื่องสำคัญที่ประธานต้องการแจ้ง — ที่ประชุมเพียงรับทราบ |
| ๒ | เรื่องรับรองรายงานการประชุมครั้งที่แล้ว | พิจารณารับรองรายงานครั้งก่อน — มีหรือไม่มีแก้ไข |
| ๓ | เรื่องสืบเนื่อง | ติดตามผลของวาระจากครั้งก่อนที่ยังไม่จบ |
| ๔ | เรื่องเพื่อพิจารณา | เรื่องใหม่ที่ต้องการมติที่ประชุม |
| ๕ | เรื่องอื่น ๆ | เรื่องที่ไม่ได้บรรจุในวาระล่วงหน้า |
| ๖ (ตามแต่หน่วยงาน) | เรื่องที่ค้างจากการประชุมครั้งที่แล้ว | บางหน่วยงานแยกออกจากวาระ ๓ |

## ข้อควรระวัง

- **ห้ามนำเข้า Cowork** ถ้ารายงานการประชุมมีข้อมูลส่วนบุคคลของประชาชน (เช่น รายชื่อผู้รับบริการ, เลขประจำตัวประชาชน, ประเด็นคดี) — ส่งต่อ DPO ตาม `references/06-data-safety.md`
- รายงานการประชุมที่ยังไม่ผ่านการรับรอง ถือเป็นเอกสารฉบับร่าง — เผยแพร่เฉพาะภายในคณะกรรมการ
- ลายมือชื่อผู้ตรวจรายงาน = ประธานในวันประชุมนั้น (ไม่ใช่เสมอกับประธานคณะกรรมการ ถ้าประธานติดราชการและมอบรองประธานทำหน้าที่)

```
- [ ] ตรวจมติที่ประชุมทุกวาระ (ครบและตรงตามที่ประชุมตกลง)
- [ ] ตรวจตัวเลขที่อ้างอิง (งบประมาณ จำนวนคน วันที่)
- [ ] ส่งให้ผู้ตรวจรายงาน (ประธานในวันประชุม) ลงนาม
- [ ] เวียนให้กรรมการพิจารณาก่อนรับรองในการประชุมครั้งถัดไป
- [ ] เก็บเข้าแฟ้มทะเบียนรายงานการประชุมของคณะกรรมการ
```
