# Thai Government Document Writer

Skill นี้ทำให้ Claude ร่างหนังสือราชการไทยให้ถูกต้องตาม **ระเบียบสำนักนายกรัฐมนตรีว่าด้วยงานสารบรรณ พ.ศ. 2526** (แก้ไขถึงฉบับที่ 4 พ.ศ. 2564) และมติคณะรัฐมนตรีที่เกี่ยวข้อง

## ขอบเขตของ Skill

ใช้เมื่อผู้ใช้ขอ:
- ร่าง หนังสือราชการ ทั้ง 6 ชนิดตามข้อ 9 ของระเบียบสารบรรณ
- ตรวจรูปแบบ คำขึ้นต้น คำลงท้าย สรรพนาม ของหนังสือราชการ
- จัดรูปแบบเอกสารตามมาตรฐาน (ฟอนต์ ขอบกระดาษ การใช้เลขไทย)

**ไม่ใช่ขอบเขต:**
- การจำแนกชั้นความลับหรือชั้นข้อมูลส่วนบุคคล (defer to หน่วยงาน DPO ดู `references/06-data-safety.md`)
- การใส่เลขที่หนังสือหรือวันที่ออกเลขจริง (เป็นหน้าที่ของงานสารบรรณกลางตามข้อ 43)

## ขั้นตอนหลัก (ทำตามลำดับเสมอ)

### Preflight A — ตรวจชั้นข้อมูลก่อน

ก่อนเริ่มร่าง ให้ถามผู้ใช้ว่าเอกสารนี้มี**ข้อมูลส่วนบุคคลของประชาชน** เลขประจำตัวประชาชน ข้อมูลสุขภาพ ข้อมูลคดี ข้อมูลทางการเงินรายบุคคล หรือชั้นความลับของทางราชการหรือไม่

ถ้าใช่หรือไม่แน่ใจ → อ่านและแสดงข้อความใน `references/06-data-safety.md` ทันที **อย่าร่างต่อ** จนกว่าผู้ใช้จะยืนยันว่าได้ปรึกษาเจ้าหน้าที่คุ้มครองข้อมูลส่วนบุคคล (DPO) ของหน่วยงานแล้ว

### Preflight B — เลือกชนิดหนังสือ

ถามผู้ใช้ว่าต้องการหนังสือชนิดใดในหกชนิดนี้ (ข้อ 9):

1. หนังสือภายนอก
2. หนังสือภายใน
3. หนังสือประทับตรา
4. หนังสือสั่งการ (คำสั่ง / ระเบียบ / ข้อบังคับ)
5. หนังสือประชาสัมพันธ์ (ประกาศ / แถลงการณ์ / ข่าว)
6. หนังสือที่เจ้าหน้าที่จัดทำขึ้นหรือรับไว้เป็นหลักฐานในราชการ

ถ้าไม่ชัดเจน อ่าน `references/01-types.md` แล้วถามคำถามตัดสินใจ จากนั้นโหลดไฟล์ template ที่ตรงกับชนิด (ดูตารางในส่วน "Loading map" ด้านล่าง)

### Preflight C — ฐานะของผู้รับ

สำหรับหนังสือภายนอก/ภายใน/ประทับตรา ถามผู้ใช้ว่า**ผู้รับคือใคร และมีฐานะ/ตำแหน่งใด** เช่น พระมหากษัตริย์ พระบรมวงศ์ พระสงฆ์ นายกรัฐมนตรี รัฐมนตรี ปลัดกระทรวง อธิบดี ผู้ว่าราชการจังหวัด หรือประชาชนทั่วไป

จากนั้นเปิด `references/04-salutations.md` ค้นแถวที่ตรง แล้วใช้ **คำขึ้นต้น / สรรพนามที่ใช้แทนผู้รับ / สรรพนามที่ใช้แทนผู้ส่ง / คำลงท้าย** ตามแถวนั้น**ทุกคำตามตาราง** ห้ามแต่งเอง

### ขั้นตอนร่าง

1. โหลด template จาก `templates/` ตามชนิดที่เลือก
2. โหลด `references/02-format.md` และทำตามรูปแบบทุกข้อ (ฟอนต์ ขอบกระดาษ ระยะห่าง)
3. โหลด `references/03-thai-numerals.md` และใช้ **เลขไทยเป็น default** ตามมติ ครม. 2 พ.ค. 2543 ใช้เลขอารบิกเฉพาะกรณียกเว้นในไฟล์
4. ใช้ placeholder ตาม `references/05-numbering.md`:
   - เลขที่หนังสือ: `[เลขที่ ........./..........]`
   - วันที่: `[วัน เดือน ปี (พ.ศ.)]`
   - ลายมือชื่อ: `[ลายมือชื่อ]`
   - ห้ามใส่ค่าจริงเด็ดขาด เพราะเลขที่หนังสือออกโดยงานสารบรรณกลางตามข้อ 43

### Self-check ก่อนส่งคำตอบ

ก่อนส่งร่างให้ผู้ใช้ ตรวจตามรายการนี้:

- [ ] ใช้เลขไทยในตัวอักษรทั้งหมด (ยกเว้นกรณีที่อยู่ในรายการยกเว้น)
- [ ] คำขึ้นต้น สรรพนาม คำลงท้าย ตรงกับแถวในภาคผนวก 2
- [ ] เลขที่หนังสือและวันที่ยังเป็น placeholder
- [ ] ฟอนต์ระบุเป็น TH Sarabun PSK หรือ TH Sarabun New ขนาด 16
- [ ] ขอบกระดาษระบุ บน 2.5 / ล่าง 2 / ซ้าย 3 / ขวา 2 ซม.
- [ ] โครงสร้างตรงกับ template ของชนิดที่เลือก

ถ้าข้อใดไม่ผ่าน แก้ก่อนส่ง

## Output contract

ทุกร่างที่ส่งกลับให้ผู้ใช้ต้อง:

- เป็นภาษาไทย ใช้ระดับภาษาทางราชการ
- ระบุฟอนต์และขอบกระดาษไว้ที่ส่วนหัวของคำตอบ (ผู้ใช้จะคัดไป Word ต่อ)
- มี placeholder สำหรับเลขที่หนังสือ วันที่ และลายมือชื่อ
- ปิดท้ายด้วย checklist ของ "สิ่งที่ผู้ใช้ต้องตรวจ/กรอกเอง" เช่น เลขที่ออกโดยสารบรรณ ตำแหน่งผู้ลงนาม สำเนาแจ้ง

ห้าม:

- แต่งชื่อระเบียบ/มาตราที่ไม่มีในไฟล์ `references/07-regulation-index.md`
- ให้คำแนะนำว่าเอกสารนี้ "ปลอดภัย" ที่จะวางในโฟลเดอร์ Cowork — ส่งไปที่ DPO เท่านั้น
- ใช้ภาษาพูด/ไม่เป็นทางการ เครื่องหมายอัศเจรีย์ คำขึ้นต้นย่อหน้าด้วย "สำหรับ"
