# รหัสประจำหน่วยงาน — ภาคผนวก ๑

อ้างอิง: **ภาคผนวก ๑** ของระเบียบสำนักนายกรัฐมนตรีว่าด้วยงานสารบรรณ พ.ศ. 2526 (และฉบับแก้ไข)

รหัสนี้ใช้ในบรรทัด "ที่" ของหนังสือราชการ ตามรูปแบบ:

```
ที่  [รหัสกระทรวง] [รหัสกรม] / [เลขลำดับ]
```

ตัวอย่าง: `ที่ มท ๐๒๐๓/ว ๔๒` = หนังสือเวียน (ว.) จากสำนักงานปลัดกระทรวงมหาดไทย เลขลำดับ ๔๒

> **สำคัญ:** ตารางในไฟล์นี้ครอบคลุมเฉพาะ**กระทรวง**และ**หน่วยงานอิสระหลัก** สำหรับ**กรม/หน่วยงานย่อย**ใต้กระทรวง รหัส 4 หลักหลังเครื่องหมายขีดอาจแตกต่างกัน — ก่อนใช้กับเอกสารจริง ให้ผู้ใช้ตรวจกับ**ทะเบียนหนังสือออก**ของหน่วยงานตนเอง เพราะเลขกรมเปลี่ยนตามโครงสร้างที่ปรับปรุง

---

## รหัสจังหวัด

จังหวัดใช้รหัส**ตัวย่อจังหวัด** + เลขกรม เช่น
- `ที่ ชม ๐๐๐๐.๒/...` = สำนักงานจังหวัดเชียงใหม่
- `ที่ นบ ๐๐๐๐.๓/...` = สำนักงานจังหวัดนนทบุรี

ตัวย่อจังหวัดทั้ง 76 + กรุงเทพมหานคร อ้างอิงจาก **ภาคผนวก ๑/๒** ของระเบียบสารบรรณ — ผู้ใช้ตรวจกับทะเบียนของจังหวัดตนเอง

## รหัสองค์กรปกครองส่วนท้องถิ่น

| ประเภท | รหัส |
|---|---|
| องค์การบริหารส่วนจังหวัด (อบจ.) | รหัสจังหวัด + เลขกรม |
| เทศบาล | **ทศ** หรือ รหัสจังหวัด + เลขเฉพาะ |
| องค์การบริหารส่วนตำบล (อบต.) | รหัสจังหวัด + เลขเฉพาะ |
| กรุงเทพมหานคร | **กท** |
| เมืองพัทยา | **มพ** |

## วิธีใช้ใน Skill

เมื่อผู้ใช้ขอร่างหนังสือและระบุชื่อหน่วยงาน:

1. ค้นรหัสกระทรวงจากตารางบนสุด
2. ใส่ในบรรทัด "ที่" — รูปแบบ `ที่ [รหัส] [........]./.........` (เลขกรม 4 หลักเป็น placeholder ให้ผู้ใช้กรอก)
3. ถ้าหน่วยงานเป็นระดับกรม/กอง ภายใต้กระทรวง — ใช้รหัสกระทรวง ไม่ต้องค้นเลขกรมเอง ปล่อยให้ผู้ใช้กรอก
4. ถ้าหน่วยงานเป็นจังหวัด/อปท. — แจ้งผู้ใช้ให้ดูทะเบียนของจังหวัด/อปท. ของตน

**ห้าม**:
- เดารหัส 4 หลักของกรม (เช่น "มท 0203" หรือ "สธ 0205") — เลขกรมเปลี่ยนตามโครงสร้าง ให้ผู้ใช้กรอก
- ใส่จุด/ขีดระหว่างตัวอักษร ("ก.ม." / "ม-ท") — ระเบียบใช้ตัวอักษรไทยติดกัน เช่น "มท" ไม่ใช่ "ม.ท."

> ผู้ใช้พึงตระหนักว่า ตารางนี้รวบรวมจากการสังเกตเอกสารราชการที่เผยแพร่และจากภาคผนวก ๑ — รหัสกระทรวงและรหัสหน่วยงานอิสระที่อยู่ในตารางนี้ใช้กันมานานและมีความเสถียร แต่หน่วยงานที่จัดตั้งใหม่หรือปรับชื่อในช่วงไม่นานนี้อาจมีรหัสที่ต่างไป ก่อนใช้ในเอกสารจริง ให้ตรวจกับสารบรรณกลางของหน่วยงานเสมอ
