# ข้อผิดพลาดที่พบบ่อยในหนังสือราชการ

รายการนี้รวบรวมจาก คู่มือ ก.พ. / OCSC / สำนักงานปลัดของแต่ละกระทรวง และระเบียบสารบรรณ พ.ศ. 2526 + ฉบับที่ 4 พ.ศ. 2564 พร้อมเทียบกับ template และ reference ที่มีในซ Skill นี้

ใช้ไฟล์นี้เป็น checklist ขั้นสุดท้ายก่อนส่งร่าง — โหลดเฉพาะเมื่อผู้ใช้สั่ง `/reviewthaiofficialdoc` หรือเมื่อผู้ใช้ขอให้ตรวจร่างที่ทำไว้แล้ว

---

## 1. หมวด เลข + รูปแบบ

| ❌ ผิด | ✅ ถูก | เหตุผล |
|---|---|---|
| ใช้เลขอารบิก (1, 2, 3) เป็น default ในเนื้อหา | ใช้เลขไทย (๑, ๒, ๓) เป็น default | มติ ครม. 2 พ.ค. 2543 (ดู `03-thai-numerals.md`) |
| ใช้เลขไทยในจำนวนเงินทุกที่ | ใช้เลขอารบิกในจำนวนเงินและตารางตัวเลข | ข้อยกเว้นมติ ครม. 2 พ.ค. 2543 |
| ใช้ฟอนต์ Cordia New / TH SarabunIT9 / Tahoma | ใช้ TH Sarabun PSK หรือ TH Sarabun New | คู่มือการพิมพ์หนังสือราชการ (นร 0106/ว 2019) |
| ขนาดฟอนต์ 14 หรือ 18 พอยต์ | ขนาด 16 พอยต์ | คู่มือการพิมพ์ |
| ขอบกระดาษ บน 1.5 / ซ้าย 2 ซม. | บน 2.5 / ล่าง 2 / ซ้าย 3 / ขวา 2 ซม. | ดู `02-format.md` |
| ใส่ครุฑในบันทึกข้อความ | บันทึกข้อความ**ไม่มี**ครุฑ — มีเฉพาะหัว "บันทึกข้อความ" | ระเบียบสารบรรณ |
| ครุฑขนาดเดียวกันทุกชนิด | หนังสือภายนอก/คำสั่ง = 3 ซม. ; ประทับตรา/ประกาศ = 1.5 ซม. | ภาคผนวก 3 ของระเบียบสารบรรณ |

## 2. หมวด คำขึ้นต้น + คำลงท้าย

| ❌ ผิด | ✅ ถูก | เหตุผล |
|---|---|---|
| "เรียน [พระสงฆ์]" | "นมัสการ [พระสงฆ์]" + "ขอนมัสการด้วยความเคารพ" | ภาคผนวก 2 (ดู `04-salutations.md`) |
| "เรียน นายกรัฐมนตรี" + "ขอแสดงความนับถือ" | "กราบเรียน นายกรัฐมนตรี" + "ขอแสดงความนับถืออย่างยิ่ง" | ภาคผนวก 2 — แถว 13 ตำแหน่งสูง |
| "เรียน" + "ขอแสดงความนับถืออย่างยิ่ง" | ผสมข้ามแถวภาคผนวก 2 ห้าม — ใช้ทั้ง 4 คอลัมน์ของแถวเดียวกัน | ภาคผนวก 2 |
| ใส่ "ขอแสดงความนับถือ" ในบันทึกข้อความ | บันทึกข้อความ**ไม่มี**คำลงท้าย — ลงชื่อ + ตำแหน่งโดยตรง | ระเบียบสารบรรณ |
| "เรียน ผู้ว่าราชการจังหวัด" ในหนังสือประทับตรา | "ถึง ผู้ว่าราชการจังหวัด" — หนังสือประทับตราใช้ "ถึง" | ระเบียบสารบรรณ ข้อ 15 |

## 3. หมวด สำนวน + ภาษา

| ❌ ผิด | ✅ ถูก | เหตุผล |
|---|---|---|
| ขึ้นต้นย่อหน้าด้วย "สำหรับ" | ใช้ "ตามที่..." (ตอบหนังสือ) / "ด้วย..." (เรื่องใหม่) / "เนื่องจาก..." แทน | คู่มือสารบรรณห้ามใช้ "สำหรับ" ขึ้นต้นย่อหน้า |
| ใส่ "ครับ" / "ค่ะ" ในเนื้อหา | ใช้ภาษาทางการ — ห้ามใช้คำลงท้ายแบบบทสนทนา | ธรรมเนียมราชการ |
| ใช้เครื่องหมาย "!" หรือ "?" | ห้ามใช้ในหนังสือราชการ | ธรรมเนียมราชการ |
| "เรียน + ตำแหน่ง + ครับ/ค่ะ" | "เรียน + ตำแหน่ง" — ไม่มีคำลงท้ายส่วนตัว | ภาคผนวก 2 |
| ใช้ภาษาผสมไทย-อังกฤษ ("approve" / "monitor" / "implement") | ใช้คำไทย — เห็นชอบ / กำกับติดตาม / ดำเนินการ | คู่มือ ก.พ. |
| ผสมระดับภาษา (เป็นทางการ ↔ ไม่เป็นทางการ) | ใช้ระดับภาษาทางการสม่ำเสมอตลอดฉบับ | คู่มือสารบรรณ |
| ใช้ "และ/หรือ" ในข้อความเชิงสั่งการ | ใช้ "และ" หรือ "หรือ" อย่างใดอย่างหนึ่ง — ห้ามรวมเครื่องหมาย / ในข้อสั่งการ | คู่มือนิติการ |

## 4. หมวด โครงสร้างเนื้อหา

| ❌ ผิด | ✅ ถูก | เหตุผล |
|---|---|---|
| ตอบหนังสือฉบับก่อนแต่ไม่ใส่ "อ้างถึง" | ระบุ "อ้างถึง [ที่ + วันที่]" ของหนังสือฉบับก่อนใต้ "เรื่อง" | ระเบียบสารบรรณ — รูปแบบหนังสือภายนอก |
| ระบุ "สิ่งที่ส่งมาด้วย" แต่ไม่ได้แนบจริง | ตรวจเอกสารแนบก่อนส่ง — ถ้าไม่มีให้ลบส่วนนี้ออก | ความรับผิดของผู้ร่าง |
| ลืม "จึงเรียนมาเพื่อ..." ในย่อหน้าสุดท้าย | ทุกหนังสือภายนอก/ภายในต้องจบด้วย "จึงเรียนมาเพื่อ[โปรดทราบ/พิจารณา/อนุมัติ]" | คู่มือสารบรรณ |
| คำสั่งที่ไม่มี "อาศัยอำนาจตาม..." | ระบุฐานอำนาจกฎหมาย/ระเบียบที่ใช้ออกคำสั่งเสมอ | หลักนิติศาสตร์ + คู่มือนิติการ |
| คำสั่งที่ไม่มี "ทั้งนี้ ตั้งแต่..." | ปิดด้วย "ทั้งนี้ ตั้งแต่บัดนี้เป็นต้นไป" หรือ "ตั้งแต่วันที่ ... เป็นต้นไป" | คู่มือนิติการ |
| ลำดับข้อแตกต่างกัน (๑ → 1.1 → (๑.๒)) | ใช้รูปแบบเดียวสม่ำเสมอ ๑ → ๑.๑ → (๑) | คู่มือสารบรรณ |
| เรื่องยาวเกิน 2 บรรทัด | ตัดให้กระชับ 1-2 บรรทัด ตอบ "เรื่องอะไร?" ได้ทันที | คู่มือสารบรรณ |

## 5. หมวด ลายมือชื่อ + ตำแหน่ง

| ❌ ผิด | ✅ ถูก | เหตุผล |
|---|---|---|
| ลงลายมือชื่อแล้วไม่ใส่ชื่อ-นามสกุลในวงเล็บ | (ชื่อ-นามสกุล ตัวบรรจง) ใต้ลายมือชื่อเสมอ | ระเบียบสารบรรณ |
| ใส่ตำแหน่งของผู้ร่าง (ไม่ใช่ผู้ลงนาม) | ตำแหน่งต้องเป็นของ**ผู้มีอำนาจลงนามตามกฎหมาย** | กฎหมายว่าด้วยอำนาจการลงนาม |
| ลืมเว้น 4 บรรทัดสำหรับลายมือชื่อ | เว้น 4 บรรทัดระหว่างคำลงท้ายและวงเล็บชื่อ | คู่มือการพิมพ์ |
| ใส่ "ฯพณฯ" หน้าชื่อตัวเอง | "ฯพณฯ" ใช้เฉพาะเมื่ออ้างถึงผู้ดำรงตำแหน่งสูงในย่อหน้าของหนังสือ ไม่ใช่หน้าลายมือชื่อตนเอง | ราชาศัพท์ + ธรรมเนียม |
| ใส่ตำแหน่งเดิมที่พ้นแล้ว | ใช้ตำแหน่งปัจจุบันที่มีอำนาจลงนามในวันที่ลงนาม | กฎหมาย |

## 6. หมวด เลขที่หนังสือ + วันที่

| ❌ ผิด | ✅ ถูก | เหตุผล |
|---|---|---|
| ใส่เลขที่หนังสือเองตอนร่าง | เว้น `[เลขที่ ........./..........]` รอสารบรรณกลาง | ระเบียบสารบรรณ ข้อ 43 |
| ใส่วันที่จริงตอนร่าง | เว้น `[วัน เดือน ปี พ.ศ.]` รอสารบรรณกลาง | ระเบียบสารบรรณ ข้อ 43 |
| ใช้รหัสประจำหน่วยงานผิด | ตรวจกับภาคผนวก 1 (ดู `10-agency-codes.md`) | ภาคผนวก 1 |
| ใส่ "ว." (เวียน) ทั้งที่ไม่ใช่หนังสือเวียน | "ว." ใช้เฉพาะหนังสือถึงหลายผู้รับ | ระเบียบสารบรรณ |

## วิธีใช้ในการตรวจร่าง

1. โหลดไฟล์นี้ + ร่างที่ผู้ใช้แนบ
2. ไล่หมวด 1-6 ตามลำดับ
3. รายงานผลเป็นตาราง: **หมวด | สิ่งที่พบในร่าง | คำแนะนำ | ระดับความสำคัญ**
4. ระดับความสำคัญ:
   - **สำคัญ (must-fix)**: ผิดระเบียบ/มติ ครม. ส่งไม่ได้
   - **ปานกลาง (should-fix)**: ผิดธรรมเนียม ควรแก้
   - **แต่ง (nice)**: ดีขึ้นได้แต่ไม่ผิด
