# เลขที่หนังสือและวันที่ — Placeholder Rules

## หลักสำคัญ

ตาม**ระเบียบสำนักนายกรัฐมนตรีว่าด้วยงานสารบรรณ พ.ศ. 2526 ข้อ 43**:

> "เมื่อเจ้าหน้าที่ของหน่วยงานสารบรรณกลางได้รับเรื่องแล้ว ให้ลงทะเบียนส่งหนังสือในทะเบียนหนังสือส่ง โดยให้ลงวันเดือนปีที่ลงทะเบียน และเลขลำดับของทะเบียนหนังสือส่งเรียงลำดับติดต่อกันไปตลอดปีปฏิทิน"

**ผู้ร่างเอกสารไม่ได้เป็นผู้กำหนดเลขที่หนังสือและวันที่** เลขที่ออกโดยงานสารบรรณกลางของหน่วยงาน ตามรหัสตัวอักษรประจำหน่วยงาน (ภาคผนวก ๑ ของระเบียบสารบรรณ) เรียงลำดับติดต่อกันตลอดปีปฏิทิน

## Skill ต้องใส่ placeholder เสมอ

ห้าม Claude แต่งเลขที่หนังสือ วันที่ออกเลข หรือเลขลำดับเอง ใช้ placeholder ดังนี้:

| ตำแหน่ง | Placeholder |
|---|---|
| เลขที่หนังสือ | `[เลขที่ ........./..........]` (รหัสหน่วยงาน/เลขลำดับ) |
| วัน เดือน ปี ในส่วนหัวของหนังสือ | `[วัน เดือน ปี (พ.ศ.)]` |
| ลายมือชื่อ | (เว้นที่ว่าง 4 บรรทัด) `[ลายมือชื่อ]` |
| ชื่อเต็มผู้ลงนาม | `(……………………………)` หรือ `(ชื่อ-นามสกุล)` |
| ตำแหน่ง | `(ตำแหน่งของผู้ลงนาม)` |
| วันที่ในตอนท้ายเอกสาร (สำหรับคำสั่ง/ประกาศ) | `สั่ง ณ วันที่ [วัน เดือน ปี (พ.ศ.)]` หรือ `ประกาศ ณ วันที่ ...` |

## รหัสประจำหน่วยงาน (ภาคผนวก ๑ — ตัวอย่าง)

ผู้ใช้ต้องทราบรหัสของหน่วยงานตน เช่น:

- สำนักนายกรัฐมนตรี: นร
- กระทรวงกลาโหม: กห
- กระทรวงการคลัง: กค
- กระทรวงการต่างประเทศ: กต
- กระทรวงเกษตรและสหกรณ์: กษ
- กระทรวงมหาดไทย: มท
- กระทรวงศึกษาธิการ: ศธ
- กระทรวงสาธารณสุข: สธ
- กระทรวงยุติธรรม: ยธ
- กระทรวงคมนาคม: คค
- กระทรวงพาณิชย์: พณ

(รายการเต็มอยู่ในภาคผนวก ๑ ของระเบียบสารบรรณ — Skill ไม่จำทั้งหมด ผู้ใช้ระบุเอง)

## รูปแบบเลขที่หนังสือ

`[รหัสกระทรวง][รหัสกรม][รหัสกอง]/[เลขลำดับ]`

ตัวอย่าง: `ศธ ๐๒๐๑/๑๒๓` = กระทรวงศึกษาธิการ / สำนักงานปลัดกระทรวง / กลุ่มเลข ๐๑ / เลขลำดับที่ ๑๒๓

ผู้ร่างจะรู้ "ศธ ๐๒๐๑/" (รหัสประจำหน่วย) แต่**เลขลำดับท้าย ๑๒๓ ออกโดยสารบรรณกลาง** เท่านั้น

## ที่ Skill ต้องบอกผู้ใช้ในทุกร่าง

ตอนจบของทุกร่าง ให้ใส่ checklist สั้น ๆ ว่าผู้ใช้ต้องเอาไปดำเนินการต่อ:

```
สิ่งที่ต้องดำเนินการก่อนเสนอลงนาม
- [ ] ส่งให้งานสารบรรณกลางออกเลขที่หนังสือ
- [ ] ลงวัน เดือน ปี ที่ออกเลข
- [ ] ตรวจชื่อ-นามสกุลและตำแหน่งของผู้ลงนาม
- [ ] ตรวจสำเนาแจ้ง (ถ้ามี)
- [ ] เสนอผู้บังคับบัญชาตามลำดับชั้น
```
