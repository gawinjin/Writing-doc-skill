# ราชาศัพท์ — Primer สำหรับหนังสือถึงพระบรมวงศานุวงศ์

> **คำเตือนสำคัญ:** ไฟล์นี้เป็น *primer* (คู่มือเบื้องต้น) เท่านั้น — **ไม่ใช่คู่มือมาตรฐาน** ก่อนส่งหนังสือถึงพระบรมวงศ์ใด ๆ ผู้ใช้ **ต้องตรวจกับ ราชบัณฑิตยสภา (royin.go.th) หรือ สำนักพระราชวัง** เนื่องจากราชาศัพท์มีความซับซ้อนและการใช้ผิดเป็นเรื่องที่สังเกตได้ชัดเจนยิ่ง

อ้างอิง: ภาคผนวก ๒ ของระเบียบสารบรรณ พ.ศ. 2526 + พจนานุกรมฉบับราชบัณฑิตยสภา + คู่มือกระทรวงมหาดไทย

---

## ๑. สรรพนามผู้พูด/ผู้รับ ตามชั้นพระอิสริยยศ

(สรุปจากภาคผนวก ๒ — ดูตารางเต็มและคำขึ้นต้น/ลงท้ายใน `04-salutations.md`)

| ชั้นผู้รับ | สรรพนามแทนผู้รับ | สรรพนามแทนผู้ส่ง |
|---|---|---|
| พระบาทสมเด็จพระเจ้าอยู่หัว | ใต้ฝ่าละอองธุลีพระบาท | ข้าพระพุทธเจ้า |
| สมเด็จพระบรมราชินี / พระบรมราชชนนี / พระยุพราช / พระบรมราชกุมารี | ใต้ฝ่าละอองพระบาท | ข้าพระพุทธเจ้า |
| พระบรมวงศ์ชั้นเจ้าฟ้า | ใต้ฝ่าพระบาท | ข้าพระพุทธเจ้า |
| พระบรมวงศ์ชั้นพระองค์เจ้า / พระอนุวงศ์ชั้นพระเจ้าวรวงศ์เธอพระองค์เจ้า | ใต้ฝ่าพระบาท | ข้าพระพุทธเจ้า |
| พระอนุวงศ์ชั้นพระวรวงศ์เธอพระองค์เจ้า | ฝ่าพระบาท | เกล้ากระหม่อม / เกล้ากระหม่อมฉัน (หญิง) |
| พระอนุวงศ์ชั้นหม่อมเจ้า | ฝ่าพระบาท | กระหม่อม / หม่อมฉัน (หญิง) |
| สมเด็จพระสังฆราชเจ้า | ใต้ฝ่าพระบาท | ข้าพระพุทธเจ้า |
| สมเด็จพระสังฆราช | ฝ่าพระบาท | เกล้ากระหม่อม |
| สมเด็จพระราชาคณะ / รองสมเด็จพระราชาคณะ | พระคุณท่าน / พระคุณเจ้า | กระผม / ดิฉัน |
| พระราชาคณะ | พระคุณท่าน | กระผม / ดิฉัน |
| พระภิกษุสงฆ์ทั่วไป | ท่าน | กระผม / ดิฉัน |

## ๒. กริยา-เชิญ/รายงาน (แทน "เรียน / บอก / แจ้ง")

| ผู้รับ | กริยาที่ใช้ |
|---|---|
| พระมหากษัตริย์ / พระบรมราชินี / พระยุพราช | **กราบบังคมทูล** |
| พระบรมวงศ์ชั้นเจ้าฟ้า | **กราบทูล** |
| พระบรมวงศ์ชั้นพระองค์เจ้า | **ทูล** |
| พระสงฆ์ระดับสูง / พระสงฆ์ทั่วไป | **นมัสการ** |

## ๓. กริยา-ให้/ส่ง (แทน "ให้ / ส่ง / มอบ")

| ผู้รับ | กริยาที่ใช้ | หมายเหตุ |
|---|---|---|
| พระมหากษัตริย์ — ของชิ้นเล็ก ถือถวายได้ | **ทูลเกล้าทูลกระหม่อมถวาย** (เขียนย่อ "ทูลเกล้าฯ ถวาย" — อ่านเต็ม) | สิ่งของที่หยิบจับถวายในพระหัตถ์ได้ |
| พระมหากษัตริย์ — ของชิ้นใหญ่/ส่งมอบสถานที่ | **น้อมเกล้าน้อมกระหม่อมถวาย** (ย่อ "น้อมเกล้าฯ ถวาย") | สิ่งของขนาดใหญ่ ที่ดิน อาคาร |
| พระบรมวงศ์ชั้นเจ้าฟ้า/พระองค์เจ้า | **ทูลเกล้าฯ ถวาย** หรือ **ทูลถวาย** | |
| พระสงฆ์ | **ถวาย** | ใช้คำเดี่ยวได้ |

## ๔. โครงสร้างหนังสือกราบบังคมทูล

ลำดับองค์ประกอบบังคับ (สำหรับหนังสือถึงพระบาทสมเด็จพระเจ้าอยู่หัว):

```
๑. คำขึ้นต้น (centered, top of letter):
   "ขอเดชะฝ่าละอองธุลีพระบาทปกเกล้าปกกระหม่อม"

๒. คำเรียก/บอกเรื่อง:
   "ข้าพระพุทธเจ้า [ชื่อ-นามสกุล] [ตำแหน่ง]
    ขอพระราชทานพระบรมราชวโรกาสกราบบังคมทูล [เรื่อง...]"

๓. เนื้อหา (ใช้ราชาศัพท์ครบทุกประโยค):
   - กริยาเชิญใช้ "กราบบังคมทูล"
   - สรรพนามผู้รับ "ใต้ฝ่าละอองธุลีพระบาท"
   - สรรพนามผู้ส่ง "ข้าพระพุทธเจ้า"

๔. คำลงท้าย (กลางหน้า ก่อนลายมือชื่อ):
   "ควรมิควรแล้วแต่จะทรงพระกรุณาโปรดเกล้าโปรดกระหม่อม ขอเดชะ
    ข้าพระพุทธเจ้า [ชื่อ-นามสกุล]
    [ตำแหน่ง]"
```

สำหรับชั้นต่ำกว่า (เจ้าฟ้า / พระองค์เจ้า / หม่อมเจ้า) ใช้คำขึ้นต้น/ลงท้ายตามแถวที่ตรงในตาราง `04-salutations.md` — โครงสร้างคล้ายกันแต่คำเฉพาะต่างกัน

## ๕. ข้อห้ามที่พบบ่อยที่สุด ๕ ข้อ

1. **ห้ามใช้ "ทรง" นำหน้ากริยาที่เป็นราชาศัพท์อยู่แล้ว**
   - ❌ ทรงเสด็จ / ทรงเสวย / ทรงประชวร / ทรงโปรด / ทรงตรัส
   - ✅ เสด็จ / เสวย / ประชวร / โปรด / ตรัส
   - "ทรง" ใช้ได้กับ**คำนาม**เพื่อทำเป็นกริยา (เช่น ทรงพระอักษร = เขียน, ทรงพระดำเนิน = เดิน)

2. **ห้ามใช้ "ทรง" ซ้อนกับ "พระราชทาน"**
   - ❌ ทรงพระราชทานพระบรมราโชวาท
   - ✅ พระราชทานพระบรมราโชวาท

3. **ห้ามใช้ "ถวาย" คำเดียวกับพระบาทสมเด็จพระเจ้าอยู่หัว**
   - ❌ ถวายของขวัญ
   - ✅ ทูลเกล้าทูลกระหม่อมถวาย (ของชิ้นเล็ก) หรือ น้อมเกล้าน้อมกระหม่อมถวาย (ของชิ้นใหญ่)

4. **ห้ามผสมชั้นพระอิสริยยศในการเลือกกริยา**
   - ❌ ใช้ "กราบบังคมทูล" กับพระบรมวงศ์ชั้นเจ้าฟ้า (ใช้ "กราบทูล")
   - ❌ ใช้ "ทูล" กับพระมหากษัตริย์ (ใช้ "กราบบังคมทูล")
   - ตรวจชั้นผู้รับใน `04-salutations.md` ทุกครั้ง

5. **ห้ามละคำลงท้ายหรือใช้คำลงท้ายผิดชั้น**
   - หนังสือถึงพระบาทสมเด็จพระเจ้าอยู่หัว ต้องจบด้วย "ควรมิควรแล้วแต่จะทรงพระกรุณาโปรดเกล้าโปรดกระหม่อม ขอเดชะ" + ลายมือชื่อ + ชื่อ + ตำแหน่ง — ห้ามตัดให้สั้น

## วิธีใช้ใน Skill

เมื่อผู้ใช้ขอร่างหนังสือถึงพระบรมวงศานุวงศ์:

1. **ถามชั้นพระอิสริยยศของผู้รับให้ชัดเจน** — พระมหากษัตริย์? เจ้าฟ้า? พระองค์เจ้า? หม่อมเจ้า? พระสงฆ์ระดับใด?
2. **โหลดทั้ง `04-salutations.md` และไฟล์นี้** — ใช้ตาราง ภาคผนวก ๒ จาก `04-salutations.md` เป็นหลัก ใช้ไฟล์นี้สำหรับเลือกกริยาและตรวจข้อห้าม
3. **ใส่คำเตือนเด่นชัดในผลลัพธ์**:
   ```
   ⚠ คำเตือนสำคัญ
   ราชาศัพท์เป็นเรื่องที่ผิดง่ายและสังเกตได้ชัดเจน
   ก่อนเสนอลงนามและส่งจริง ขอแนะนำให้:
   - ตรวจกับราชบัณฑิตยสภา หรือ สำนักพระราชวัง
   - เสนอหัวหน้าหน่วยงานราชการในพระองค์ตรวจอีกครั้ง
   - หากเป็นหนังสือสำคัญ (เช่น ถวายความอาลัย / ขอพระราชทาน)
     ส่งให้สำนักงานราชเลขานุการในพระองค์ตรวจก่อน
   ```
4. **ห้ามทำเอง**: อย่าตัดสินใจระหว่างราชาศัพท์ที่ใกล้เคียงกัน (เช่น เสด็จ vs เสด็จพระราชดำเนิน) — ส่งให้ผู้เชี่ยวชาญตรวจ
