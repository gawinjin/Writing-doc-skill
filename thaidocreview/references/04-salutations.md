# ภาคผนวก ๒ — คำขึ้นต้น สรรพนาม คำลงท้าย ในหนังสือราชการ

อ้างอิง: ภาคผนวก ๒ ของระเบียบสำนักนายกรัฐมนตรีว่าด้วยงานสารบรรณ พ.ศ. 2526 (และฉบับแก้ไข)

**กฎ:** เลือกแถวตามฐานะของผู้รับ ใช้ทั้ง 4 คอลัมน์ของแถวนั้นพร้อมกัน ห้ามผสมข้ามแถว

## วิธีใช้ตารางใน Skill

1. ผู้ใช้บอกว่าผู้รับคือใคร (ตำแหน่ง/ฐานะ)
2. หาแถวที่ตรงในตารางหลัก
3. คัดทั้ง 4 คอลัมน์ไปใช้ในร่างพร้อมกัน
4. ถ้าไม่พบแถวที่ตรงเป๊ะ ใช้แถว "บุคคลทั่วไป" เป็น default และแจ้งผู้ใช้ให้ตรวจ

ตัวอย่าง: ผู้รับ = "ปลัดกระทรวงศึกษาธิการ" → แถวบุคคลทั่วไป → คำขึ้นต้น "เรียน ปลัดกระทรวงศึกษาธิการ" / สรรพนามแทนผู้รับ "ท่าน" / สรรพนามแทนผู้ส่ง "กระผม" หรือ "ดิฉัน" / คำลงท้าย "ขอแสดงความนับถือ"
