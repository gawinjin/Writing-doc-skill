# Data Safety Deferral Block

## ใช้ block นี้เมื่อใด

ใช้ทุกครั้งที่ผู้ใช้ตอบ "ใช่" หรือ "ไม่แน่ใจ" ใน Preflight A หรือเมื่อผู้ร่างพบสัญญาณว่าเอกสารอาจมี:

- ข้อมูลส่วนบุคคลของประชาชน (ชื่อ-นามสกุล + ข้อมูลอื่นที่ระบุตัวได้)
- เลขประจำตัวประชาชน
- ที่อยู่ เบอร์โทร อีเมลของบุคคล
- ข้อมูลสุขภาพ ข้อมูลคดี ข้อมูลภาษี
- ข้อมูลทางการเงินรายบุคคล
- ข้อมูลผู้ร้องเรียน ผู้แจ้งเบาะแส
- ชั้นความลับของทางราชการ (ลับ ลับมาก ลับที่สุด ปกปิด)

## ข้อความที่ Claude ต้องส่งให้ผู้ใช้ (ใช้ verbatim)

```
ขออนุญาตหยุดร่างก่อน

จากที่แจ้งไว้ เอกสารนี้อาจมีข้อมูลส่วนบุคคลของประชาชนหรือชั้นความลับของทางราชการ
Skill นี้ไม่ทำหน้าที่จำแนกชั้นข้อมูลหรือรับรองความปลอดภัยของช่องทางที่ใช้ประมวลผล

ก่อนใช้ Claude (หรือเครื่องมือ AI ใด ๆ) ในการร่างเอกสารชนิดนี้ ขอให้:

1. ปรึกษาเจ้าหน้าที่คุ้มครองข้อมูลส่วนบุคคล (DPO) ของหน่วยงาน
   หรือผู้รับผิดชอบตาม พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562
2. ตรวจสอบนโยบายและแนวปฏิบัติด้านการรักษาความมั่นคงปลอดภัยของข้อมูลของหน่วยงาน
3. ทำตามระเบียบว่าด้วยการรักษาความลับของทางราชการ พ.ศ. 2544
   (ถ้าเป็นเอกสารชั้นความลับ)

ทางเลือกที่ปลอดภัยกว่า:

- ลบ/ปิดบังข้อมูลที่ระบุตัวบุคคลออกก่อนนำเข้า Claude
  (เช่น แทน "นาย ก. เลขประจำตัว 1234567890123" ด้วย "ผู้ร้อง ก.")
- ร่างเอกสารเป็นโครงสร้างเปล่าก่อน แล้วค่อยกรอกข้อมูลจริงในระบบปิดของหน่วยงาน
- ใช้ระบบสารสนเทศของหน่วยงานที่ผ่านการประเมินความปลอดภัยแล้ว

หากต้องการให้ร่างต่อโดยไม่มีข้อมูลส่วนบุคคล/ชั้นความลับ
กรุณาแจ้งว่า "ร่างต่อโดยไม่ใส่ข้อมูลจริง ใช้ placeholder แทน" และยืนยันว่า
ได้ปรึกษา DPO ของหน่วยงานแล้ว
```

## อย่าทำสิ่งเหล่านี้

- **อย่า**บอกผู้ใช้ว่าแพลน Pro / Max / Team / Enterprise "ปลอดภัย" สำหรับข้อมูลประชาชน
- **อย่า**บอกผู้ใช้ว่า Zero Data Retention (ZDR) ของ Enterprise ครอบคลุม Cowork sessions (Anthropic ระบุชัดว่า ZDR ไม่ครอบคลุม Cowork)
- **อย่า**ตัดสินเองว่าข้อมูลใดเป็น "ข้อมูลส่วนบุคคล" ตามนิยาม PDPA — เป็นหน้าที่ของ DPO ของหน่วยงาน
- **อย่า**ร่างต่อจนกว่าผู้ใช้จะยืนยันสองอย่าง: (ก) ปรึกษา DPO แล้ว (ข) จะใช้ placeholder ไม่ใส่ข้อมูลจริง

## ถ้าผู้ใช้ยืนยันใช้ placeholder ต่อได้

Claude ดำเนินการร่างต่อได้ตามขั้นตอนปกติ (Preflight B → C → ร่าง) โดย:

- ใช้ `[ชื่อผู้ร้อง]` `[เลขประจำตัวประชาชน]` `[ที่อยู่]` `[หมายเลขโทรศัพท์]` แทนข้อมูลจริง
- ระบุท้ายร่างว่า "ผู้ใช้ต้องกรอกข้อมูลจริงในระบบปิดของหน่วยงาน ไม่ใช่ในช่องทางนี้"
