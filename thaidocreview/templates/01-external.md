## คำแนะนำการกรอก

| ส่วน | คำแนะนำ |
|---|---|
| ที่ | ใช้รหัสประจำหน่วยงาน (ภาคผนวก ๑) + เลขลำดับ — เลขลำดับเว้นว่าง รอสารบรรณกลาง |
| วัน เดือน ปี | เว้นว่าง รอวันที่ลงทะเบียนของสารบรรณกลาง (ใช้เลขไทย) |
| เรื่อง | กระชับ ชัดเจน ๑-๒ บรรทัด ตอบคำถาม "เรื่องอะไร?" ได้ทันที |
| คำขึ้นต้น/คำลงท้าย | เลือกตาม `references/04-salutations.md` ตามฐานะของผู้รับ |
| อ้างถึง | ใช้เมื่อหนังสือฉบับนี้ตอบหรือต่อจากหนังสือฉบับก่อน ระบุที่และวันที่ของฉบับก่อน |
| สิ่งที่ส่งมาด้วย | ระบุจำนวนและประเภท เช่น "๑ ฉบับ" "๑ ชุด" "๑ เล่ม" |
| ย่อหน้าสุดท้าย | ลงท้ายด้วยคำขอ/คำเชิญที่ตรงกับวัตถุประสงค์: "เพื่อโปรดทราบ" / "เพื่อโปรดพิจารณา" / "เพื่อโปรดอนุมัติ" / "เพื่อโปรดดำเนินการต่อไป" |
| สำเนาแจ้ง | ถ้ามีให้พิมพ์ที่มุมล่างซ้าย ก่อนส่วนราชการเจ้าของเรื่อง: "สำเนาแจ้ง: [ตำแหน่ง/หน่วยงาน]" |

## ห้าม

- ห้ามใส่เลขที่หนังสือและวันที่จริงเอง
- ห้ามใช้คำขึ้นต้น/คำลงท้ายที่ไม่ตรงกับฐานะผู้รับในภาคผนวก ๒
- ห้ามขึ้นต้นย่อหน้าด้วย "สำหรับ"
- ห้ามใช้เครื่องหมาย ! หรือ ?

## checklist ปิดท้ายร่าง

```
สิ่งที่ต้องดำเนินการก่อนเสนอลงนาม
- [ ] ส่งให้งานสารบรรณกลางออกเลขที่หนังสือและลงวันที่
- [ ] ตรวจชื่อ-นามสกุลและตำแหน่งของผู้ลงนาม
- [ ] ตรวจคำขึ้นต้น/ลงท้ายให้ตรงกับฐานะของผู้รับ
- [ ] เตรียมเอกสารแนบตามที่ระบุใน "สิ่งที่ส่งมาด้วย"
- [ ] เสนอผู้บังคับบัญชาตามลำดับชั้น
```
