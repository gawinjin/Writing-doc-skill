# Template — หนังสือสั่งการ (คำสั่ง / ระเบียบ / ข้อบังคับ)

ใช้สำหรับสั่งให้ปฏิบัติ มี 3 ชนิดย่อย เลือก template ตามชนิด

**รูปแบบ:** TH Sarabun PSK/New ขนาด 16 / ขอบ 2.5/2/3/2 ซม. / เลขไทย default

---

## ๑) คำสั่ง

ใช้สั่งการให้ปฏิบัติ โดยชอบด้วยกฎหมาย เช่น คำสั่งแต่งตั้ง คำสั่งมอบหมายงาน คำสั่งย้าย

```
                                  [ครุฑ ขนาด 3 ซม. กึ่งกลางหน้า]


                                       คำสั่ง[ส่วนราชการ]
                                  ที่ [เลขลำดับที่/ปี พ.ศ. — เลขไทย]

                              เรื่อง  [ชื่อเรื่องของคำสั่ง]
                            ─────────────────────


        [ย่อหน้าเหตุผล/ที่มา — "ด้วย..." หรือ "โดยที่..." หรืออ้างถึงกฎหมาย/ระเบียบ
         ที่ให้อำนาจ]


        อาศัยอำนาจตามความใน [ระบุมาตรา/ข้อ ของกฎหมาย/ระเบียบ ที่ให้อำนาจ]
[ผู้มีอำนาจ]จึงมีคำสั่ง[ดังต่อไปนี้ / ดังนี้]


        ข้อ ๑  [ข้อความสั่งการ — กระชับ เป็นรูปธรรม]

        ข้อ ๒  [ข้อความสั่งการต่อเนื่อง]

        ข้อ ๓  [การมีผลบังคับใช้ เช่น "ทั้งนี้ ตั้งแต่บัดนี้เป็นต้นไป" หรือ
                "ทั้งนี้ ตั้งแต่วันที่ ........... เป็นต้นไป"]


                       สั่ง ณ วันที่ [วัน เดือน ปี (พ.ศ.)]


                                  [เว้น 4 บรรทัดสำหรับลายมือชื่อ]


                                  (ชื่อ-นามสกุล)
                                  (ตำแหน่งของผู้มีอำนาจสั่ง)
```

## ๒) ระเบียบ

ใช้กำหนดวิธีปฏิบัติงานเป็นการประจำ โดยอาศัยอำนาจของกฎหมายหรือไม่ก็ได้

```
                                  [ครุฑ ขนาด 3 ซม. กึ่งกลางหน้า]


                                       ระเบียบ[ส่วนราชการ]
                              ว่าด้วย[ชื่อเรื่องของระเบียบ]
                                  พ.ศ. [ปี — เลขไทย]
                            ─────────────────────


        [ย่อหน้าเหตุผล — "โดยที่เป็นการสมควร..." หรือ "เพื่อให้..."]


        อาศัยอำนาจตามความใน [กฎหมายที่ให้อำนาจ]
[ผู้มีอำนาจ]จึงวางระเบียบไว้ดังต่อไปนี้


        ข้อ ๑  ระเบียบนี้เรียกว่า "ระเบียบ[ชื่อเต็ม] พ.ศ. ๒๕..."

        ข้อ ๒  ระเบียบนี้ให้ใช้บังคับตั้งแต่[วันถัดจากวันประกาศ / วันที่ ...] เป็นต้นไป

        ข้อ ๓  ในระเบียบนี้
                "..." หมายความว่า ...
                "..." หมายความว่า ...

        ข้อ ๔  [เนื้อหาหลัก]

        ข้อ ๕  [เนื้อหาหลัก]

        ข้อ ๖  ให้[ตำแหน่ง]รักษาการตามระเบียบนี้


                       ประกาศ ณ วันที่ [วัน เดือน ปี (พ.ศ.)]


                                  (ชื่อ-นามสกุล)
                                  (ตำแหน่งของผู้มีอำนาจ)
```

## ๓) ข้อบังคับ

ใช้กำหนดข้อปฏิบัติที่อาศัยอำนาจของกฎหมาย — โครงสร้างใกล้เคียงระเบียบ ใช้คำว่า "ข้อบังคับ" แทน

```
                                       ข้อบังคับ[ส่วนราชการ]
                              ว่าด้วย[ชื่อเรื่องของข้อบังคับ]
                                  พ.ศ. [ปี — เลขไทย]
                            ─────────────────────

[เหตุผล + อาศัยอำนาจตามกฎหมาย + ข้อต่าง ๆ + ผู้รักษาการ]
[คำลงท้ายเหมือนระเบียบ]
```

## คำแนะนำการกรอก

| ส่วน | คำแนะนำ |
|---|---|
| ครุฑ | ใช้ครุฑขนาด 3 ซม. กึ่งกลาง |
| เลขที่คำสั่ง | รูปแบบ "ที่ [เลขลำดับ]/[ปี พ.ศ.]" — เลขลำดับเว้นว่าง รอสารบรรณกลาง |
| ชื่อเรื่อง | ระบุให้ชัดในบรรทัดแรก |
| อาศัยอำนาจ | ระบุมาตรา/ข้อของกฎหมาย/ระเบียบที่ให้อำนาจ — Claude ห้ามแต่งเลขมาตราเอง ขอให้ผู้ใช้บอกหรือเว้น `[มาตรา ...]` ให้ผู้ใช้กรอก |
| ข้อ ๑, ๒, ๓ | ใช้ "ข้อ" + เลขไทย เรียงลำดับ |
| สั่ง/ประกาศ ณ วันที่ | เว้นว่าง รอวันที่ออกเลขจริง |
| ผู้รักษาการ | สำหรับระเบียบ/ข้อบังคับเท่านั้น |

## ห้าม

- ห้าม Claude แต่งเลขมาตรา/ชื่อกฎหมายที่ไม่มีจริง ถ้าไม่ทราบให้เว้น `[ระบุมาตราของกฎหมายที่ให้อำนาจ]` ไว้
- ห้ามใส่ "เรียน" หรือ "ขอแสดงความนับถือ" — ไม่ใช่หนังสือติดต่อ
- ห้ามใส่เลขที่และวันที่จริงเอง

## checklist ปิดท้ายร่าง

```
สิ่งที่ต้องดำเนินการก่อนเสนอลงนาม
- [ ] ตรวจมาตรา/ข้อของกฎหมายที่อ้างอำนาจ
- [ ] ตรวจชื่อ-ตำแหน่งของผู้มีอำนาจสั่ง/วางระเบียบ
- [ ] ส่งให้งานสารบรรณกลางออกเลขที่และลงวันที่
- [ ] หากเป็นระเบียบ/ข้อบังคับ ตรวจว่าระบุผู้รักษาการแล้วหรือยัง
- [ ] เสนอผ่านฝ่ายกฎหมายของหน่วยงานก่อนเสนอลงนาม
```
