# Quick Reference — ข้อผิดพลาดที่พบบ่อย

ฉบับเต็มอยู่ที่ `thaidocreview/references/08-common-errors.md` (ติดตั้งคู่กัน)

## Top errors

| ❌ ผิด | ✅ ถูก | เหตุผล |
|---|---|---|
| ใช้เลขอารบิกในวันที่และข้อความ | ใช้เลขไทยเป็น default | มติ ครม. 2 พ.ค. 2543 |
| "เรียน [พระสงฆ์]" | "นมัสการ [พระสงฆ์]" | ภาคผนวก 2 |
| "เรียน นายกรัฐมนตรี" | "กราบเรียน นายกรัฐมนตรี" | ภาคผนวก 2 (13 ตำแหน่งสูง) |
| ขึ้นต้นย่อหน้าด้วย "สำหรับ" | ใช้ "ตามที่..." / "ด้วย..." / "เนื่องจาก..." แทน | คู่มือสารบรรณ |
| ใส่เลขที่หนังสือและวันที่จริงตอนร่าง | เว้น placeholder ให้สารบรรณกลาง | ข้อ 43 |
| "บันทึกข้อความ" + "ขอแสดงความนับถือ" | บันทึกข้อความ**ไม่มี**คำลงท้าย | ระเบียบสารบรรณ |
| "หนังสือประทับตรา" + "เรียน" | ใช้ "ถึง" สำหรับหนังสือประทับตรา | ระเบียบสารบรรณ |
| ใช้ครุฑในบันทึกข้อความ | บันทึกข้อความ**ไม่มี**ครุฑ | ระเบียบสารบรรณ |
| ใช้ "ครับ/ค่ะ" ในเนื้อหา | ใช้ภาษาทางการเสมอ | ธรรมเนียมราชการ |
| เครื่องหมาย ! หรือ ? | ห้ามใช้ในหนังสือราชการ | ธรรมเนียมราชการ |
