# Review Checklist — หนังสือราชการ

ใช้ตามลำดับนี้ทุกครั้ง

## 1. รูปแบบ (Format)
- [ ] ฟอนต์: TH Sarabun PSK หรือ TH Sarabun New ขนาด 16
- [ ] ขอบกระดาษ: บน 2.5 / ล่าง 2 / ซ้าย 3 / ขวา 2 ซม.
- [ ] ครุฑ (ถ้าเป็นหนังสือภายนอก / คำสั่ง / ประกาศ): ขนาด 3 ซม. (ภายนอก/คำสั่ง) หรือ 1.5 ซม. (ประทับตรา/ประกาศ)
- [ ] บันทึกข้อความ: **ไม่มี** ครุฑ, มีแค่หัว "บันทึกข้อความ"

## 2. เลขไทย vs อารบิก (มติ ครม. 2 พ.ค. 2543)
- [ ] วันที่ เดือน พ.ศ. → เลขไทย
- [ ] จำนวนคน/รายการ/ลำดับข้อ → เลขไทย
- [ ] เบอร์โทรศัพท์ ที่อยู่ → เลขไทย
- [ ] **ยกเว้น**: จำนวนเงิน/ตารางตัวเลข/เอกสารปนภาษาต่างประเทศ → อารบิกได้

## 3. คำขึ้นต้น/ลงท้าย (ภาคผนวก 2)
- [ ] เลือกแถวตามฐานะผู้รับ
- [ ] ใช้ทั้ง 4 คอลัมน์ของแถวเดียวกัน (ห้ามผสม)
- [ ] บุคคลทั่วไป (รวมข้าราชการทุกระดับ): "เรียน" + "ขอแสดงความนับถือ"
- [ ] 13 ตำแหน่งสูง (นายกฯ/ประธานสภา/ฯลฯ): "กราบเรียน" + "ขอแสดงความนับถืออย่างยิ่ง"
- [ ] พระสงฆ์: "นมัสการ" + "ขอนมัสการด้วยความเคารพ"
- [ ] หนังสือประทับตรา: ใช้ "ถึง" (ไม่ใช่ "เรียน") + ไม่มีคำลงท้าย

## 4. โครงสร้างเนื้อหา
- [ ] ย่อหน้าแรกขึ้นต้นด้วย "ตามที่..." (ตอบหนังสือก่อน) หรือ "ด้วย..." (เรื่องใหม่)
- [ ] ย่อหน้าสุดท้ายขึ้นต้นด้วย "จึงเรียนมาเพื่อ..." (ภายนอก/ภายใน) หรือ "ทั้งนี้ ตั้งแต่..." (คำสั่ง)
- [ ] **ไม่ขึ้นต้นย่อหน้าด้วย "สำหรับ"** (ห้ามตามคู่มือ)
- [ ] ถ้ามี "อ้างถึง" ต้องระบุที่และวันที่ของหนังสือฉบับก่อน
- [ ] ถ้ามี "สิ่งที่ส่งมาด้วย" ต้องแนบจริงและระบุจำนวน

## 5. เลขที่หนังสือ + วันที่ (ข้อ 43)
- [ ] เลขที่หนังสือเป็น placeholder `[เลขที่ ........./..........]` (เว้นว่างให้สารบรรณกลาง)
- [ ] วันที่เป็น placeholder `[วัน เดือน ปี พ.ศ.]` (เว้นว่างให้สารบรรณกลาง)
- [ ] รหัสประจำหน่วยงานต้องตรงกับภาคผนวก 1

## 6. ลายมือชื่อ
- [ ] เว้น 4 บรรทัดสำหรับลายมือชื่อ
- [ ] วงเล็บใต้ลายมือชื่อ: (ชื่อ-นามสกุล ตัวบรรจง)
- [ ] บรรทัดถัดไป: ตำแหน่งของผู้ลงนาม
- [ ] ตำแหน่งของผู้ลงนามต้องเป็นผู้มีอำนาจลงนามตามกฎหมาย

## 7. ภาษา
- [ ] ไม่ใช้ "ครับ/ค่ะ"
- [ ] ไม่ใช้เครื่องหมาย ! หรือ ?
- [ ] ระดับภาษาเป็นทางการสม่ำเสมอ
- [ ] ไม่ใช้ภาษาพูด/แสลง

## 8. ป้ายกำกับ (ถ้ามี)
- [ ] ด่วน/ด่วนมาก/ด่วนที่สุด: ตำแหน่งและสีถูกต้อง (ดู references/09 ของ thaidocreview)
- [ ] ลับ/ลับมาก/ลับที่สุด: ตำแหน่งและสีถูกต้อง
