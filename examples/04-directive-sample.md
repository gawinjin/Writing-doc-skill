# ตัวอย่างคำสั่ง — แต่งตั้งคณะกรรมการ

**สถานการณ์สมมุติ:** อธิบดีกรม ก. ลงนามคำสั่งแต่งตั้งคณะกรรมการตรวจรับพัสดุของโครงการพัฒนาระบบสารสนเทศ

## จุดที่ตัวอย่างนี้สาธิต

| เทคนิค | จุดที่อยู่ในร่าง |
|---|---|
| หัว "คำสั่ง[หน่วยงาน]" — กึ่งกลางหน้า ใหญ่กว่าเนื้อหา | บรรทัด "คำสั่งกรม ก." |
| ที่หนังสือ — รูปแบบ "ที่ X/พ.ศ." (พ.ศ. เลขไทยเสมอ) | "ที่ [เลขที่ ........./๒๕๖๙]" |
| เรื่อง — กึ่งกลาง ๒-๓ บรรทัด ตามด้วยขีดยาว | "เรื่อง แต่งตั้งคณะกรรมการ..." + "-----" |
| ๓ ส่วนของเนื้อหา: ความเป็นมา → อาศัยอำนาจ → จึงแต่งตั้ง | ๓ บล็อกแรก |
| ระบุ**อาศัยอำนาจตาม**ข้อใดของกฎหมาย/ระเบียบใด | "อาศัยอำนาจตามความในข้อ ๒๕ และข้อ ๑๗๖..." |
| รายชื่อกรรมการเป็นข้อ ๑, ๒, ๓ — ใช้เลขไทย | ๕ รายการ |
| อำนาจหน้าที่แยกเป็นข้อย่อย (๑), (๒), (๓), (๔) | บล็อกท้าย |
| ปิดด้วย "ทั้งนี้ ตั้งแต่บัดนี้เป็นต้นไป" | บรรทัดก่อน "สั่ง ณ วันที่" |
| "สั่ง ณ วันที่ [placeholder]" — สำหรับสารบรรณกรอก | placeholder |
| ลายมือชื่อ + ชื่อ + ตำแหน่ง — ผู้มีอำนาจลงนามตามกฎหมาย | บล็อกท้าย |

## คำที่ใช้ในคำสั่ง — สำนวนมาตรฐาน

| สำนวน | ใช้เมื่อ |
|---|---|
| "ตามที่ ... นั้น" | เกริ่นความเป็นมา |
| "เพื่อให้ ... เป็นไปด้วยความเรียบร้อย ..." | เหตุผล/วัตถุประสงค์ |
| "อาศัยอำนาจตามความในข้อ ... แห่ง ..." | ฐานอำนาจตามกฎหมาย/ระเบียบ |
| "จึงแต่งตั้ง ... ดังต่อไปนี้" / "จึงมีคำสั่ง ... ดังนี้" | ตัวคำสั่ง |
| "ให้ ... มีอำนาจหน้าที่ ดังนี้" | ระบุอำนาจ |
| "ทั้งนี้ ตั้งแต่บัดนี้เป็นต้นไป" / "ทั้งนี้ ตั้งแต่วันที่ ... เป็นต้นไป" | ผลใช้บังคับ |
| "สั่ง ณ วันที่ ..." | บรรทัดก่อนลายมือชื่อ |

## ข้อแตกต่าง คำสั่ง vs ระเบียบ vs ข้อบังคับ

| ประเภท | ใช้เมื่อ | คำเปิด |
|---|---|---|
| **คำสั่ง** | สั่งการเฉพาะกรณี/บุคคล/ครั้ง | "อาศัยอำนาจตามความในข้อ ... จึงแต่งตั้ง/มอบหมาย/อนุญาต ..." |
| **ระเบียบ** | กำหนดวิธีปฏิบัติเป็นการทั่วไป ใช้ได้ต่อเนื่อง | "อาศัยอำนาจตามความใน ... จึงวางระเบียบไว้ดังต่อไปนี้" |
| **ข้อบังคับ** | กำหนดข้อปฏิบัติที่มีผลผูกพันบุคคลภายในเป็นการทั่วไป | "อาศัยอำนาจตามความใน ... จึงออกข้อบังคับไว้ดังต่อไปนี้" |

## checklist ปิดท้ายร่าง

```
สิ่งที่ผู้ใช้ต้องดำเนินการก่อนเสนอลงนาม
- [ ] ตรวจฐานอำนาจ (ระเบียบ/มาตรา) ที่อ้างถึงให้ตรงกับเนื้อหา
- [ ] ตรวจตำแหน่งของกรรมการให้สอดคล้องกับโครงสร้างหน่วยงานปัจจุบัน
- [ ] ส่งให้งานสารบรรณกลางออกเลขที่คำสั่งและลงวันที่
- [ ] ตรวจชื่อ-นามสกุลและอำนาจการลงนามของผู้สั่ง (ตำแหน่งระบุในคำสั่งต้องเป็นผู้มีอำนาจตามกฎหมาย)
- [ ] เก็บสำเนาเข้าทะเบียนคำสั่งของหน่วยงาน
- [ ] เวียนสำเนาให้กรรมการแต่ละคนทราบ
```
