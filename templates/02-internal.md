# Template — หนังสือภายใน (บันทึกข้อความ)

ใช้สำหรับติดต่อในกระทรวง/กรม/จังหวัดเดียวกัน หรือเสนอเรื่องต่อผู้บังคับบัญชา ใช้กระดาษ "บันทึกข้อความ"

**รูปแบบ:** TH Sarabun PSK/New ขนาด 16 (คำว่า "บันทึกข้อความ" ขนาด 29 หรือ 20) / ขอบ 2.5/2/3/2 ซม. / เลขไทย default / **ไม่มีครุฑ**

---

```
                            บันทึกข้อความ

ส่วนราชการ  [ส่วนราชการเจ้าของเรื่อง — ระบุชื่อกอง/ฝ่าย โทรศัพท์ภายใน]
ที่  [เลขที่ ........./..........]                  วันที่  [วัน เดือน ปี (พ.ศ.)]
เรื่อง  [ชื่อเรื่องสั้น กระชับ]


เรียน  [ตำแหน่งของผู้รับ]


        [ย่อหน้าที่ ๑ — เกริ่นเรื่อง ใช้ "ตามที่..." หรือ "ด้วย..."]


        [ย่อหน้าที่ ๒ — รายละเอียด เหตุผล ข้อเท็จจริง]


        [ย่อหน้าที่ ๓ — ความเห็น/ข้อเสนอ พร้อมเหตุผลประกอบ]


        จึงเรียนมาเพื่อ[โปรดทราบ / โปรดพิจารณา / โปรดอนุมัติ / โปรดสั่งการ]


                                                       [เว้น 4 บรรทัดสำหรับลายมือชื่อ]


                                                       (ชื่อ-นามสกุล)
                                                       (ตำแหน่ง)
```

## คำแนะนำการกรอก

| ส่วน | คำแนะนำ |
|---|---|
| ส่วนราชการ | ระบุหน่วยงานเจ้าของเรื่องให้ละเอียด (กระทรวง > กรม > กอง > ฝ่าย) + เบอร์โทรภายใน |
| ที่ | เลขที่ใช้รหัสภายในของหน่วยงาน — เลขลำดับเว้นว่าง |
| วันที่ | เว้นว่าง รอวันที่ลงทะเบียน |
| เรื่อง | กระชับ ตอบ "เรื่องอะไร" ใน ๑ บรรทัด |
| เรียน | ใช้ "เรียน [ตำแหน่ง]" ตามภาคผนวก ๒ — สำหรับบุคคลทั่วไป (รวมข้าราชการระดับสูง) ใช้ "เรียน" |
| ย่อหน้าสุดท้าย | จบด้วย "จึงเรียนมาเพื่อ..." แล้วเลือกคำต่อท้ายตามวัตถุประสงค์ |
| ลงชื่อ | ไม่มีคำลงท้ายอย่าง "ขอแสดงความนับถือ" — ลงชื่อตำแหน่งโดยตรง |

## ห้าม

- ห้ามใส่ครุฑ
- ห้ามใส่ "ขอแสดงความนับถือ" หรือคำลงท้ายแบบหนังสือภายนอก
- ห้ามใส่เลขที่หนังสือและวันที่จริงเอง
- ห้ามขึ้นต้นย่อหน้าด้วย "สำหรับ"

## checklist ปิดท้ายร่าง

```
สิ่งที่ต้องดำเนินการก่อนเสนอลงนาม
- [ ] ส่งให้งานสารบรรณกลางออกเลขที่และลงวันที่
- [ ] ตรวจชื่อ-นามสกุลและตำแหน่งของผู้ลงนาม
- [ ] ตรวจตำแหน่งของผู้รับให้ถูกต้อง
- [ ] เตรียมเอกสารประกอบ (ถ้ามี)
```
