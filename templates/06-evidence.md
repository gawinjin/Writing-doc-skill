# Template — หนังสือที่เจ้าหน้าที่จัดทำขึ้นหรือรับไว้เป็นหลักฐาน

มี 4 ชนิดย่อย เลือก template ตามเรื่อง

**รูปแบบทั่วไป:** TH Sarabun PSK/New ขนาด 16 / ขอบ 2.5/2/3/2 ซม. / เลขไทย default

---

## ๑) หนังสือรับรอง

ใช้รับรองสถานะ/ข้อเท็จจริงของบุคคล นิติบุคคล หรือหน่วยงาน

```
                                  [ครุฑ ขนาด 3 ซม. กึ่งกลางหน้า]


                                    หนังสือรับรอง
                                  เลขที่ [...../.....]


        [ส่วนราชการ] ขอรับรองว่า [ชื่อ-นามสกุล / ชื่อนิติบุคคล] [รายละเอียดที่รับรอง
        เช่น เป็นข้าราชการสังกัด ตำแหน่ง... อายุงาน... / เป็นนิติบุคคลจดทะเบียนเมื่อ...]


        หนังสือรับรองฉบับนี้ออกให้เพื่อ [จุดประสงค์]


                       ให้ไว้ ณ วันที่ [วัน เดือน ปี (พ.ศ.)]


                                  [เว้น 4 บรรทัดสำหรับลายมือชื่อ]


                                  (ชื่อ-นามสกุล)
                                  (ตำแหน่งของผู้มีอำนาจรับรอง)
```

## ๒) รายงานการประชุม

บันทึกความคิดเห็นและมติของที่ประชุม

```
                            รายงานการประชุม[ชื่อคณะ/กลุ่ม]
                                  ครั้งที่ [ลำดับ]/[ปี พ.ศ.]
                              เมื่อวันที่ [วัน เดือน ปี (พ.ศ.)]
                                  ณ [สถานที่ประชุม]
                            ─────────────────────


ผู้มาประชุม
        ๑. [ชื่อ-ตำแหน่ง] (ประธาน)
        ๒. [ชื่อ-ตำแหน่ง]
        ๓. [ชื่อ-ตำแหน่ง]
        ...

ผู้ไม่มาประชุม (ถ้ามี)
        ๑. [ชื่อ-ตำแหน่ง] (ติดราชการ)

ผู้เข้าร่วมประชุม (ถ้ามี)
        ๑. [ชื่อ-ตำแหน่ง]


เริ่มประชุมเวลา [HH.MM] น.


ระเบียบวาระที่ ๑  เรื่องที่ประธานแจ้งให้ทราบ
        [สรุปเรื่องที่ประธานแจ้ง]
        มติที่ประชุม: รับทราบ

ระเบียบวาระที่ ๒  เรื่องรับรองรายงานการประชุมครั้งที่แล้ว
        [สรุปการรับรอง]
        มติที่ประชุม: รับรองโดย[เอกฉันท์ / มีการแก้ไข]

ระเบียบวาระที่ ๓  เรื่องสืบเนื่อง
        ๓.๑ [เรื่อง]
                [สรุปการอภิปราย]
                มติที่ประชุม: [...]

ระเบียบวาระที่ ๔  เรื่องเพื่อพิจารณา
        ๔.๑ [เรื่อง]
                [สรุปการอภิปราย]
                มติที่ประชุม: [...]

ระเบียบวาระที่ ๕  เรื่องอื่น ๆ (ถ้ามี)


ปิดประชุมเวลา [HH.MM] น.


                                  [ผู้จดรายงาน]
                                  (ชื่อ-นามสกุล)
                                  (ตำแหน่ง)


                                  [ผู้ตรวจรายงาน]
                                  (ชื่อ-นามสกุล)
                                  (ตำแหน่ง)
```

## ๓) บันทึก

ใช้เสนอเรื่องระหว่างเจ้าหน้าที่ในระดับต่ำกว่ากรม หรือเสนอผู้บังคับบัญชา (กรณีไม่ใช่บันทึกข้อความ)

```
                                  บันทึก


เรื่อง  [ชื่อเรื่อง]


        [ย่อหน้าที่ ๑ — เรื่องที่ต้องการบันทึก]


        [ย่อหน้าที่ ๒ — รายละเอียดและเหตุผล]


        [ย่อหน้าสุดท้าย — ความเห็น/ข้อเสนอ/คำขอ]


                                  [ลายมือชื่อ]
                                  (ชื่อ-นามสกุล)
                                  (ตำแหน่ง)
                                  [วัน เดือน ปี (พ.ศ.)]
```

## ๔) หนังสืออื่น

หนังสือ/เอกสารอื่นใดที่เกิดจากการปฏิบัติงาน เช่น ภาพถ่าย ฟิล์ม แถบบันทึกเสียง/ภาพ — รูปแบบไม่ตายตัว ขึ้นกับลักษณะของวัสดุ

ให้ระบุที่ส่วนหัว/ฉลาก/ทะเบียน:
- ชื่อเรื่อง/หัวข้อ
- วัน เดือน ปี ที่จัดทำ
- ผู้จัดทำ/ผู้รับผิดชอบ
- ส่วนราชการเจ้าของเรื่อง
- เลขทะเบียนของหน่วยงาน

---

## คำแนะนำการกรอก

| ส่วน | คำแนะนำ |
|---|---|
| หนังสือรับรอง | ระบุข้อเท็จจริงที่รับรองให้ชัด ใส่จุดประสงค์ของการรับรอง |
| รายงานการประชุม | ระบุครั้งที่/ปี + สถานที่ + เวลาเริ่ม-ปิด + รายชื่อผู้มา-ผู้ไม่มา + วาระและมติ |
| บันทึก | ใช้เมื่อเป็นการบันทึกระหว่างเจ้าหน้าที่ระดับต่ำกว่ากรม — ถ้าเสนอ ผบ. ใช้บันทึกข้อความ (template 02) แทน |
| มติที่ประชุม | ระบุชัดว่ารับทราบ / รับรอง / อนุมัติ / ไม่อนุมัติ / มอบหมายให้ใครทำอะไรเมื่อไหร่ |

## ห้าม

- ห้ามแต่งมติที่ประชุมเอง — ผู้ใช้ต้องให้ข้อมูลจากที่ประชุมจริง
- ห้ามรับรองข้อเท็จจริงที่ไม่มีหลักฐาน — Skill ใช้ placeholder `[ระบุข้อเท็จจริงที่รับรอง]` ให้ผู้ใช้กรอก
- ห้ามใส่ข้อมูลส่วนบุคคลของประชาชนในรายงานการประชุมโดยไม่ได้รับอนุญาต

## checklist ปิดท้ายร่าง

```
สิ่งที่ต้องดำเนินการก่อนใช้
- [ ] ตรวจข้อเท็จจริงและตัวเลขให้ถูกต้อง
- [ ] ตรวจรายชื่อผู้เข้าประชุม/ผู้ลงนาม
- [ ] (รายงานการประชุม) เวียนให้ที่ประชุมรับรองในครั้งถัดไป
- [ ] ลงทะเบียนตามระบบสารบรรณของหน่วยงาน
```
