# Template — หนังสือประชาสัมพันธ์ (ประกาศ / แถลงการณ์ / ข่าว)

ใช้สำหรับเผยแพร่ข้อมูลสู่สาธารณะ มี 3 ชนิดย่อย

**รูปแบบ:** TH Sarabun PSK/New ขนาด 16 / ขอบ 2.5/2/3/2 ซม. / เลขไทย default / ใช้กระดาษตราครุฑสำหรับประกาศและแถลงการณ์

---

## ๑) ประกาศ

ใช้แจ้งให้ทราบหรือชี้แนะแนวทางปฏิบัติ เช่น ประกาศรับสมัครงาน ประกาศผลสอบ ประกาศจัดซื้อจัดจ้าง

```
                                  [ครุฑ ขนาด 3 ซม. กึ่งกลางหน้า]


                                       ประกาศ[ส่วนราชการ]
                              เรื่อง  [ชื่อเรื่องของประกาศ]
                            ─────────────────────


        [ย่อหน้าที่ ๑ — เกริ่นเหตุผลและที่มา ใช้ "ด้วย..." หรือ "โดยที่..."]


        [ย่อหน้าที่ ๒ — เนื้อหาของประกาศ — รายละเอียดที่ต้องการประกาศ
         อาจแบ่งเป็นข้อ ๑, ๒, ๓ ถ้ามีหลายประเด็น]


        ๑. [รายละเอียด]
        ๒. [รายละเอียด]
        ๓. [รายละเอียด]


        [ย่อหน้าสุดท้าย — สรุป วันมีผลบังคับใช้ หรือช่องทางติดต่อสอบถาม]


                       ประกาศ ณ วันที่ [วัน เดือน ปี (พ.ศ.)]


                                  [เว้น 4 บรรทัดสำหรับลายมือชื่อ]


                                  (ชื่อ-นามสกุล)
                                  (ตำแหน่งของผู้มีอำนาจประกาศ)
```

## ๒) แถลงการณ์

ใช้ทำความเข้าใจเหตุการณ์/กรณี/กิจการของทางราชการ มักใช้เมื่อต้องชี้แจงต่อสาธารณะ

```
                                  [ครุฑ ขนาด 3 ซม. กึ่งกลางหน้า]


                                       แถลงการณ์[ส่วนราชการ]
                              เรื่อง  [ชื่อเรื่องของแถลงการณ์]
                            ─────────────────────


        [ย่อหน้าที่ ๑ — สถานการณ์/เหตุการณ์/ที่มา]


        [ย่อหน้าที่ ๒ — ข้อเท็จจริงและการดำเนินการของทางราชการ]


        [ย่อหน้าที่ ๓ — จุดยืน คำขอความร่วมมือ หรือคำชี้แจงเพิ่มเติม]


                       [ส่วนราชการ]
                       [วัน เดือน ปี (พ.ศ.)]
```

## ๓) ข่าว

ใช้เผยแพร่ข้อมูลทั่วไป โครงสร้างยืดหยุ่นกว่าประกาศ/แถลงการณ์

```
                                  ข่าว[ส่วนราชการ]
                              ฉบับที่ [ลำดับ]/[ปี พ.ศ.]
                              เรื่อง  [ชื่อเรื่องของข่าว]
                            ─────────────────────

[เนื้อหาข่าว — เริ่มด้วยประเด็นหลัก ตอบ ใคร ทำอะไร ที่ไหน เมื่อไหร่ ทำไม อย่างไร]

[รายละเอียดและบริบทเพิ่มเติม]

[สรุปและช่องทางติดต่อหากต้องการข้อมูลเพิ่มเติม]


                                  [ส่วนราชการ]
                                  [วัน เดือน ปี (พ.ศ.)]


สอบถามข้อมูลเพิ่มเติม:
[หน่วยงาน/บุคคลผู้รับผิดชอบ]
โทร. [หมายเลขโทรศัพท์]
อีเมล [อีเมล]
```

## คำแนะนำการกรอก

| ส่วน | คำแนะนำ |
|---|---|
| ชื่อเรื่อง | กระชับ ตรงประเด็น ๑-๒ บรรทัด |
| เลขฉบับ (ข่าว) | ใช้รูปแบบ "ฉบับที่ [ลำดับ]/[ปี]" — เลขลำดับเว้นว่าง |
| เนื้อหาประกาศ/แถลงการณ์ | แบ่งย่อหน้าให้ชัด ใช้ภาษากระชับ ตรงประเด็น |
| ประกาศ/แถลงการณ์ ณ วันที่ | เว้นว่าง รอลงวันที่จริง |
| ลงนาม | ประกาศและแถลงการณ์ลงนามโดยผู้มีอำนาจ — ข่าวอาจไม่ต้องลงนามรายบุคคล แต่ระบุส่วนราชการ |

## ห้าม

- ห้ามใส่ "เรียน" หรือ "ขอแสดงความนับถือ" — ไม่ใช่หนังสือติดต่อ
- ห้ามใช้ภาษาที่ก่อให้เกิดความเข้าใจผิดต่อสาธารณะ
- ห้ามใส่ข้อมูลส่วนบุคคลของประชาชนในข่าว/ประกาศโดยไม่ได้รับอนุญาตตาม PDPA
- ห้ามใส่เลขฉบับและวันที่จริงเอง

## checklist ปิดท้ายร่าง

```
สิ่งที่ต้องดำเนินการก่อนเผยแพร่
- [ ] ตรวจข้อเท็จจริงและตัวเลขให้ถูกต้อง
- [ ] ตรวจว่าไม่มีข้อมูลส่วนบุคคลที่ต้องคุ้มครอง
- [ ] เสนอผู้บังคับบัญชาอนุมัติเนื้อหาก่อนเผยแพร่
- [ ] ส่งให้ฝ่ายประชาสัมพันธ์/โฆษกเผยแพร่ตามช่องทางที่กำหนด
- [ ] ลงวันที่และเลขฉบับโดยสารบรรณกลาง
```
