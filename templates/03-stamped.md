# Template — หนังสือประทับตรา

ใช้แทนการลงชื่อของหัวหน้าส่วนราชการระดับกรมขึ้นไป สำหรับเรื่องที่ไม่สำคัญมากหรือเรื่องที่หัวหน้าส่วนราชการมอบอำนาจไว้

ใช้สำหรับ:
- การส่งสำเนาหนังสือ สิ่งของ เอกสาร
- การตอบรับทราบที่ไม่เกี่ยวกับการอนุญาตหรือการอนุมัติ
- การแจ้งผลที่เป็นเรื่องธรรมดา
- การเตือนเรื่องที่ค้าง
- การมอบอำนาจ การแจ้งให้ทราบว่ามีการกระทำการแทน
- เรื่องที่หัวหน้าส่วนราชการระดับกรมขึ้นไปกำหนดให้ใช้

**รูปแบบ:** TH Sarabun PSK/New ขนาด 16 / ขอบ 2.5/2/3/2 ซม. / เลขไทย default / ใช้กระดาษตราครุฑ / ประทับตราชื่อส่วนราชการแทนลายมือชื่อ

---

```
                                  [ครุฑ ขนาด 3 ซม. กึ่งกลางหน้า]


ที่ [เลขที่ ........./..........]


ถึง  [ส่วนราชการผู้รับ — ระบุชื่อหน่วยงานเต็ม]


        [ย่อหน้าที่ ๑ — เนื้อหา ใช้ "ตามที่..." หรือ "ด้วย..."]


        [ย่อหน้าที่ ๒ — รายละเอียดและจุดประสงค์]


        จึงเรียนมาเพื่อโปรด[ทราบ / ดำเนินการ]


                                                       [ส่วนราชการที่ส่งหนังสือออก]


                                  [ตราชื่อส่วนราชการ — ประทับตรงนี้]


                                                       [วัน เดือน ปี (พ.ศ.)]


[ส่วนราชการเจ้าของเรื่อง]
โทร. [หมายเลขโทรศัพท์]
```

---

## คำแนะนำการกรอก

| ส่วน | คำแนะนำ |
|---|---|
| ที่ | รหัสประจำหน่วยงาน + เลขลำดับ — เลขลำดับเว้นว่าง |
| ถึง | ใช้คำว่า "ถึง" ไม่ใช่ "เรียน" — เป็นเอกลักษณ์ของหนังสือประทับตรา |
| ตราชื่อส่วนราชการ | ประทับตราของส่วนราชการที่ส่งหนังสือออก ไม่มีการลงลายมือชื่อบุคคล |
| วันที่ | เว้นว่าง รอลงทะเบียนของสารบรรณกลาง |

## ห้าม

- ห้ามใช้คำว่า "เรียน" — ใช้ "ถึง" เท่านั้น
- ห้ามใส่ลายมือชื่อบุคคล — ใช้ตราประทับเท่านั้น
- ห้ามใส่คำลงท้าย "ขอแสดงความนับถือ"
- ห้ามใช้สำหรับเรื่องที่ต้องอนุมัติ/อนุญาต/สำคัญมาก
- ห้ามใส่เลขที่หนังสือและวันที่จริงเอง

## checklist ปิดท้ายร่าง

```
สิ่งที่ต้องดำเนินการก่อนส่ง
- [ ] ส่งให้งานสารบรรณกลางออกเลขที่และลงวันที่
- [ ] ประทับตราชื่อส่วนราชการ
- [ ] ยืนยันว่าเป็นเรื่องที่ใช้หนังสือประทับตราได้ตามที่หัวหน้าส่วนราชการกำหนด
```
